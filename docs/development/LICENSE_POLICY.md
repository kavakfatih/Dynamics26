# Project License Policy — Pending Selection

Proje acik kaynak olarak hedeflenmektedir; ancak proje sahibi tarafindan nihai lisans secimi yapilmadan bu paket otomatik olarak Apache, BSD, MIT, GPL vb. bir lisansla etiketlenmez.

Bu nedenle V0.3.0 gelistirme paketi `LICENSE` yerine bu politika belgesini icerir.

## Public release gate

Ilk kamuya acik repo/release oncesinde:

1. proje lisansi secilecek,
2. `LICENSE` dosyasi eklenecek,
3. `THIRD_PARTY_NOTICES.md` denetlenecek,
4. kaynak dosyasi header politikasina karar verilecek.

Bu tercih, lisans hakkinda kullanici adina hukuki karar vermemek icin bilincli olarak ertelenmistir.
