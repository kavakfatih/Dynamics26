## Hardening sırasında bulunan kritik hata

İlk augmented-Lagrangian implementation multiplier'ı absolute trial gap üzerinden her evaluation'da güncelliyordu. Converged state commit sonrası aynı configuration'ın yeniden evaluation'ı multiplier'ı ikinci kez artırabiliyordu.

Düzeltme: update committed gap increment'ine dönüştürüldü:

```text
lambda_trial = max(0, lambda_committed - kn*(g_trial - g_committed))
```

`VER-V110-002` aynı committed state'in tekrar evaluation'ında force/multiplier invariance test eder.

## Solver güvenlik kararları

1. Contact present ise CG reddedilir; friction tangent SPD garantili değildir.
2. Contact + checkpoint restart reddedilir; contact state henüz restart snapshot payload'ına dahil değildir.
3. Failed nonlinear step contact state'i commit edemez.
4. Line-search candidate contact history'yi accumulated state olarak kullanamaz.
