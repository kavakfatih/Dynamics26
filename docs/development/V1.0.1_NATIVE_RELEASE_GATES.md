# V1.0.1 Native Apple Silicon Release Gates

The signed binary release is accepted only when all gates below pass on a native arm64 macOS runner.

1. `uname -m == arm64`.
2. Source `PROJECT_VERSION` matches the requested release version.
3. Release build with Qt, VTK, OCCT, ARPACK and Accelerate succeeds.
4. Full CTest matrix passes.
5. `migration` and `release` label gates pass.
6. Installed `FEMCAE.app` is self-contained.
7. Every Mach-O under `Contents` is arm64-only.
8. `otool -L` contains no Homebrew/build-directory absolute dependency.
9. `LC_RPATH` contains no Homebrew/build/temp absolute path.
10. `--bundle-smoke` reaches `main()` without QPA startup.
11. Developer ID signature verifies with hardened runtime and secure timestamp.
12. ZIP notarization succeeds.
13. App ticket staples and validates.
14. DMG notarization succeeds and ticket validates.
15. `spctl --assess --type execute` accepts the application.
16. SHA256 and build provenance files are emitted with the artifacts.

A source ZIP is not equivalent to satisfying these gates.
