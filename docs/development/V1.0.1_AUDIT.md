# V1.0.1 Release Engineering Audit

## Purpose

V1.0.1 reduces macOS distribution risk without modifying FEM mathematics.

## Closed source-level items

1. **Project-file migration boundary**
   - schema 1: accepted unchanged,
   - recognized schema-less FEMCAE V0.x JSON: migrated to schema 1,
   - future schema: rejected,
   - arbitrary schema-less JSON: rejected,
   - non-numeric/negative schema: rejected.

2. **Version single-source hardening**
   - Fortran version contract = 1.0.1,
   - CMake project/shared-library version = 1.0.1,
   - GUI version comes from `PROJECT_VERSION`,
   - C API contract tests expect patch 1.

3. **Bundle dependency closure**
   `audit_bundle.sh` checks arm64-only Mach-O architecture, `otool -L`, `LC_RPATH`, Info.plist identity/version and loader-level bundle smoke.

4. **Signing/notarization automation**
   Release helper supports keychain profiles or App Store Connect API-key authentication. Audit occurs before notarization.

5. **Manual protected release workflow**
   The workflow requires explicit `workflow_dispatch`, protected `macos-release` environment and Apple signing/notary secrets.

## Native evidence not available on this host

The source-level implementation is complete, but the following are macOS evidence gates and remain unexecuted here: migration CTest with Qt, arm64 app deployment, codesign, notarization, stapling and Gatekeeper assessment.
