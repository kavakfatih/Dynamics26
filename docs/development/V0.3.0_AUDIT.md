## Sayısal denetim notu

İlk implementasyon incelemesinde determinant singularity kontrolünün boyutlu sabit eşikle yapılmasının birim ölçeğine bağımlı olacağı görüldü. Release öncesinde kontrol normalize edildi:

```text
|detJ| / scale(J)^dimension
```

Bu davranış çok küçük fakat geometrik olarak regular QUAD4 testiyle kilitlendi.
