# FEMCAE V0.6.0 — Scope Closure Audit

**Tarih:** 2026-08-29  
**Karar:** V0.6 core scope complete; native macOS backend/GUI execution gate açık.

## 1. Roadmap kapsamı

### Consistent / lumped mass matrix — PASS

Mass matrix desteği:

- TRUSS2,
- 2B beam,
- plane QUAD4,
- axisymmetric QUAD4,
- HEX8.

### Generalized eigenproblem — PASS

`Kφ = λMφ` için backend-independent facade oluşturuldu.

### ARPACK-NG — PASS, baseline

Gerçek `dsaupd/dseupd` reverse-communication backend test hostundaki ARPACK 3.9.1 ile çalıştırıldı ve dense reference eigenvalue'ları ile eşleşti.

Kapsam notu: V0.6 ARPACK yolu sparse shift-invert factorization cache değildir. Assembly sparse kalır; generalized-to-standard operator bu sürümde dense'dir. Büyük-model performans iddiası yapılmaz.

### Apple Accelerate / LAPACK — SOURCE COMPLETE / NATIVE GATE OPEN

Apple backend `DSYGV` kullanır. Bu Linux doğrulama hostunda gerçek Accelerate framework execution yapılamaz. macOS arm64 CI'da build/test gate bulunur.

### Mode shape / frequency / animation — PASS source

- `ω = sqrt(λ)`
- `f = ω/(2π)`
- `φᵀMφ=1`
- modal residual
- C API axial modal preset
- Qt result table
- mode selector
- VTK modal animation

Native Qt/VTK binary burada sertifiye edilmemiştir.

### Beam/shell + orientation altyapısı — PASS infrastructure

`orientation_frame_id` element metadata'ya eklendi; model registry doğrulaması vardır. Beam modal mass/stiffness çalışır. Shell stiffness/modal formulation tamamlandı iddiası yoktur.

## 2. Mimari denetim

Korunan ayrımlar:

```text
Node ID != Array Index != DOF ID != Equation ID
Topology != Formulation
Material != Section != Formulation
GUI != Fortran module ABI
Eigen backend != Assembly
```

`K` ve `M` aynı active equation numbering ve aynı sparsity graph üzerinden assemble edilir.

## 3. Numerical hardening

- `M` symmetry ve SPD Cholesky kontrolü,
- `K` symmetry kontrolü,
- density `> 0`,
- nonzero prescribed displacement rejection,
- unsupported backend rejection,
- requested positive mode count doğrulaması,
- mass normalization,
- deterministic eigenvector sign,
- modal residual calculation.

## 4. Verification

### VER-V060-001

Two-element TRUSS2 fixed-free modal FE model; iki discrete eigenvalue kapalı-form referansla doğrulanır.

### VER-V060-002

8-element Euler–Bernoulli cantilever; birinci bending frequency continuum analitik referansla doğrulanır.

### VER-V060-003

Free-free tek TRUSS2 axial system: stiffness nullity üzerinden bir rigid translation mode tespit edilir; pozitif flexible eigenvalue `12E/(ρL²)` ile doğrulanır.
