## Bilinçli defer edilenler

Aşağıdakiler V0.5.0 için mevcut değildir ve hazırmış gibi raporlanmamalıdır:

- arbitrary mesh GUI editing,
- generic model-handle C API,
- mesh file import,
- structured 2D/3D mesher GUI,
- arbitrary nodal/element selection viewport interaction,
- generic displacement/stress contours for arbitrary model,
- CAD geometry,
- full result database.

Bunların önemli bölümü V0.12–V0.13 full pre/post kapsamındadır. Generic C API model-handle katmanı ise GUI geliştirmesi boyunca daha erken bir ara sürümde eklenebilir.
