## Kritik mühendislik kararları

1. Linear HEX8 ve TL HEX8 ayrı formulation ID kullanır.
2. Shape gradientleri TL formulation'da `dN/dX` olarak reference configuration'da kalır.
3. `J<=0` sessizce devam etmez.
4. Residual işareti `R=f_ext-f_int` korunur.
5. Internal tangent material + geometric olarak ayrı tutulur.
6. StVK yalnız verification reference material'dır; rubber model değildir.
7. Follower-load implementasyonu olmadan follower pressure varmış gibi sonuç üretilmez.
8. Trial/commit/revert Newton solver'dan önce açık state sözleşmesi olarak bulunur.

## Verification özeti

- **PATCH-V070-001:** affine finite deformation; tüm Gauss noktalarında sabit `F/E`.
- **VER-V070-001:** pure rigid rotation objectivity.
- **VER-V070-002:** 24-column element consistent-tangent finite difference.
- **VER-V070-003:** sparse global nonlinear tangent finite difference.
- **VER-V070-004:** superposed rigid rotation; PK2 invariant, Cauchy objective rotation.
- **VER-V070-005:** finite uniaxial stretch; analytic StVK PK2/Cauchy stress.
