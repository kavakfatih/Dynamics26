## 3. Hata-yolu hardening

Aşağıdaki durumlar sessizce geçmez:

- geçersiz Newton method ID,
- geçersiz increment/tolerance seçenekleri,
- hiçbir convergence kriterinin aktif olmaması,
- nonzero prescribed displacement ile V0.8 load-control kullanımı,
- Newton iteration limit failure,
- line-search failure,
- minimum increment altına cutback,
- checkpoint DOF mismatch / invalid load factor.

Failure sonrası last committed state korunur.

## 4. Fiziksel sınır

V0.8 nonlinear çözümün mekanik ve numerik sürücüsünü doğrular. StVK yalnız reference constitutive modeldir. Büyük-strain rubber engineering için V0.9 hyperelastic material ve V0.10 mixed `u-p` gerekli olacaktır.
