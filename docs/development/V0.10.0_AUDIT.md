## 2. Kritik mimari sözleşmeler

1. Pressure DOF nodal displacement DOF değildir; element entity ID üzerinden adreslenir.
2. Hyperelastic constitutive denklemleri mixed elemente kopyalanmaz.
3. Penalty `K` ile mixed pressure unknown aynı kavram gibi sunulmaz.
4. Mixed residual convergence blok-bilinçlidir.
5. CG, saddle-point mixed sistemde kullanılmaz.
6. P0 pressure raw element result olarak saklanır; nodal smoothing yapılmaz.
