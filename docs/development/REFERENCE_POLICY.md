# Source Independence / Reference Policy

Code_Aster projenin teknik referanslarindan biridir; fakat yeni projenin kaynak tabani bagimsiz olacaktir.

## Yasaklanan uygulamalar

- Code_Aster kaynak kodunu kopyalamak.
- Python/C/C++/Fortran rutinlerini satir satir baska dile port etmek.
- Code_Aster yorumlarini Turkceye cevirerek yeni koda koymak.
- Code_Aster test inputlarini veya reference outputlarini kopyalamak.
- GPL kodu degistirip lisans bildirimini kaldirmak.

## Izin verilen referans bicimi

- genel mimari problemlerin nasil ayrildigini incelemek,
- kamuya acik FEM teorisini akademik literaturden bagimsiz turetmek,
- verification problemlerini analitik veya bagimsiz yayinlanmis referanslardan kurmak.

Her formulation dokumani, gercek matematik kaynaklarini ayri olarak listelemelidir.
