## Kritik kontrat

```text
Node ID != Array Index != DOF ID != Equation ID
```

Bu kontrat `REG-V020-001` ile dogrudan test edilir. ID degerleri bilerek storage sirasiyla alakasiz secilmistir.

## Mixed-field hazirligi

`REG-V020-002` iki node icin ayni modelde:

```text
3 displacement + 1 pressure + 3 rotation = 7 DOF/node
2 node = 14 DOF
```

numbering zincirini dogrular. Bu test mixed `u-p` formulation'in kendisi degil, gelecekteki block formulation icin veri-modeli hazirligidir.
