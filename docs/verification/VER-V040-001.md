# VER-V040-001 — Two-Bar Assembled Linear System

## Amaç

V0.4 global FEM zincirini tek testte dogrulamak:

```text
Mesh IDs
 -> DOF/constraints
 -> numbering
 -> element DOF maps
 -> sparsity graph
 -> CSR assembly
 -> local TRUSS2 stiffness
 -> external load
 -> linear solve
 -> displacement
 -> reaction
 -> equilibrium
```

## Model

Uc dugum X ekseni uzerindedir:

```text
node 100 : x = 0 m
node   7 : x = 1 m
node 900 : x = 2 m
```

Iki element:

```text
element 50 : node 100 -> node 7
element 10 : node 7   -> node 900
```

ID'ler kasitli olarak array sirasi ile ayni degildir.

Material/geometri:

```text
E = 210 GPa
A = 1.0e-4 m^2
L = 1 m / element
```

Boundary conditions:

- node 100: `ux, uy, uz = 0`,
- node 7: `uy, uz = 0`,
- node 900: `uy, uz = 0`.

Toplam 9 displacement DOF vardir; 7 constrained, 2 aktif equation kalir.

Load:

```text
Fx(node 900) = +1000 N
```

## Analitik çözüm

Her bar icin eksenel rijitlik:

```text
k = EA/L = 21,000,000 N/m
```

Aktif global sistem:

```text
[ 2k  -k ] [u2] = [   0 ]
[ -k   k ] [u3]   [1000]
```

Dolayisiyla:

```text
u2 = F/k   = 4.761904761904762e-5 m
u3 = 2F/k  = 9.523809523809524e-5 m
```

Support reaction:

```text
R1x = -1000 N
```

ve global denge:

```text
R1x + F = 0
```

## Acceptance

Test su kosullari kontrol eder:

- sparsity + assembly basarili,
- dense reference solve analitik displacement ile uyumlu,
- sparse CG ayni displacement ile uyumlu,
- support reaction `-1000 N`,
- toplam reaction + external load sifir,
- persistent entity ID sirasi equation/array sirasi varsayimina donusmez.
