# VER-V120-003 — DXF Custom Section

ASCII DXF içinde iki closed LWPOLYLINE ile hollow rectangle oluşturulur. Reader:

1. ENTITIES section'ını okur,
2. segmentleri closed contour'a bağlar,
3. enclosing-area nesting ile inner loop'u hole sınıflandırır,
4. section properties hesaplar.

Ayrıca tek açık LINE segmenti içeren DXF'nin açıkça reddedildiği doğrulanır.
