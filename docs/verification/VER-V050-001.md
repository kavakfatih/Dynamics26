# VER-V050-001 — Plane-Stress QUAD4 Affine / Traction Verification

## Amaç

QUAD4 plane-stress formulation'ın material → B-matrix → stiffness → global assembly → boundary condition → solve → reaction zincirini analitik affine çözümle doğrulamak.

## Doğrulanan özellikler

- plane-stress constitutive matrix,
- thickness scaling,
- QUAD4 stiffness integration,
- global assembly,
- prescribed DOF handling,
- displacement sonucu,
- support reaction / force equilibrium.

## Kabul ölçütü

Numerik displacement analitik uniform-strain çözümüyle test toleransı içinde eşleşmeli; toplam support reaction uygulanan dış yükü dengelemelidir.

Kaynak test: `tests/verification/ver_v050_001_plane_stress_quad4.f90`.
