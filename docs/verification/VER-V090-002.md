# VER-V090-002 — Homogeneous Hyperelastic Deformation Paths

## Amaç
Dört hyperelastic modelin temel homogeneous deformation path'lerinde sonlu ve enerjik olarak tutarlı response vermesini doğrulamak.

## Matris
Her model için `lambda=1.25` ile:

- isochoric uniaxial,
- planar tension (`J=1`),
- equibiaxial (`J=1`),
- simple shear

çalıştırılır.

## Kabul
Constitutive status OK, deforme durumda `W>0`, PK1 nominal stress sonlu.
