# VER-V100-004 — Nearly-Incompressible Locking Benchmark

## Amaç

Aynı low-order mesh ve aynı hyperelastic material için displacement-only penalty formulation ile mixed Q1/P0 formulation'ın reference-tangent bending cevabını karşılaştırmak.

## Model

- 4 adet HEX8 cantilever
- tam sabit sol yüz
- sağ yüzde toplam 100 N transverse nodal load
- Neo-Hookean `C10 = 0.5 MPa`
- `K = 10000 MPa`
- yaklaşık `K/G0 = 10^4`

## Sonuç

```text
penalty tip displacement = -4.7335e-4
mixed tip displacement   = -1.1922e-2
ratio |mixed/penalty|    = 25.1872
```

Coarse Q1 penalty model volumetric constraint nedeniyle çok daha sert davranır. Mixed Q1/P0 aynı benchmark'ta volumetric locking'i belirgin biçimde azaltır.

## Sınır

Bu bir controlled reference-tangent benchmark'tır. Tek başına Q1/P0 pair'in arbitrary meshes üzerinde inf-sup stability veya checkerboard-free production davranışını kanıtlamaz.
