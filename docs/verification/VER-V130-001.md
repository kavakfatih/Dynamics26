# VER-V130-001 — Structured HEX8 Mesh → Fortran Solve → Stress

## Amaç

Mesher çıktısının preset formül kullanmadan gerçek FEM çözüm çekirdeğine taşındığını doğrulamak.

## Problem

Unit cube, tek HEX8, lineer izotropik malzeme:

```text
E  = 1000
nu = 0.3
L  = 1
A  = 1
F  = 100
```

Minimal rigid-body constraints ile x-yönünde uniform axial loading uygulanır.

## Referans

\[
u_x=\frac{FL}{EA}=0.1
\]

\[
\sum R_x=-100
\]

\[
\sigma_{vm}=100
\]

## Doğrulanan zincir

```text
StructuredHexMesher
 -> node/connectivity C arrays
 -> fem_solve_linear_hex8_mesh
 -> Fortran model + DOF
 -> sparse assembly
 -> linear solve
 -> reaction recovery
 -> HEX8 stress recovery
```

## Beklenen sonuç

Tip ortalama displacement, toplam x reaction ve element von Mises analitik değerlerle tolerans içinde eşleşir.
