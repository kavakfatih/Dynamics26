# VER-V070-003 — Global Sparse Nonlinear Assembly Tangent

## Amaç

Element seviyesindeki doğru tangent'in DOF/equation mapping ve CSR scatter sonrasında da doğru kaldığını doğrulamak.

## Problem

Node ID'leri array sırasından bilinçli olarak farklı seçilmiş tek `TOTAL_LAGRANGIAN_HEX8` model.

Global trial displacement affine deformation'dan üretilir.

## Gate

Sparse assembled tangent dense view'e alınır ve global internal-force central finite-difference Jacobian'ıyla karşılaştırılır.

Ayrıca zero external load için:

\[
\mathbf{R}+\mathbf{f}_{int}=0
\]

doğrulanır.
