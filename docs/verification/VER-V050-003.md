# VER-V050-003 — Generic Linear Static Analysis Driver

## Problem

İki düğümlü TRUSS2:

- material registry'den `E`,
- section registry'den `A`,
- element üzerinden formulation/material/section ID,
- DOF-ID tabanlı constraint,
- DOF-ID tabanlı nodal load.

Analitik çözüm:

\[
u=FL/(EA),\qquad R=-F.
\]

## Amaç

Tek tek element rutinlerini değil, yüksek seviyeli `solve_linear_static()` akışını doğrulamak:

```text
model → numbering → element dispatch → sparse assembly → solve → DOF reconstruction → reaction
```

Node ID'leri array sırasına göre seçilmez; persistent-ID sözleşmesi korunur.

Kaynak test: `tests/verification/ver_v050_003_linear_driver.f90`.
