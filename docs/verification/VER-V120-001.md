# VER-V120-001 — Rectangle Section Properties

Dikdörtgen `b=0.04 m`, `h=0.02 m` için contour integration sonucu analitik değerlerle karşılaştırılır:

```text
A = b h
Ixx = b h^3 / 12
Iyy = h b^3 / 12
Ixy = 0
```

Centroid orijinde olmalıdır. Bu test Green-theorem section engine'in temel analytic gate'idir.
