# VER-V050-002 — 2D Euler–Bernoulli Cantilever Beam

## Problem

Tek 2-node 2B frame/beam elemanı, bir uç ankastre, diğer uçta transverse kuvvet.

Analitik çözüm:

\[
v_{tip}=FL^3/(3EI)
\]

\[
\theta_{tip}=FL^2/(2EI)
\]

## Amaç

- displacement + rotation field'larının ortak local DOF map'te birleşmesini,
- 6×6 beam stiffness'i,
- local/global transformation'ı,
- sparse assembly ve solve zincirini

doğrulamak.
