# VER-V070-004 — Superposed Rigid Rotation Objectivity

## Amaç

Objectivity'yi yalnız sıfır-strain rigid rotation ile değil, önceden deforme olmuş state üzerine superposed rotation ile doğrulamak.

İlk deformation gradient `F0`, ikinci state:

\[
\mathbf{F}_2=\mathbf{Q}\mathbf{F}_0
\]

olacak şekilde kurulur.

Beklenen:

\[
\mathbf{E}_2=\mathbf{E}_1
\]

\[
\mathbf{S}_2=\mathbf{S}_1
\]

Spatial Cauchy stress ise:

\[
\boldsymbol{\sigma}_2=\mathbf{Q}\boldsymbol{\sigma}_1\mathbf{Q}^T
\]

olmalıdır.
