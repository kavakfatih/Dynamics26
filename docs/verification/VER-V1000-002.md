# VER-V1000-002 — Disk Checkpoint / Restart

## Amaç

V0.8 in-memory nonlinear checkpoint mekanizmasını V1.0 sürümlü disk formatına taşımak ve corrupted-file davranışını doğrulamak.

## Akış

1. StVK finite-stretch nonlinear model %25 load factor'da kontrollü durdurulur.
2. Converged displacement/load-factor/step state checkpoint'e alınır.
3. Checkpoint disk dosyasına yazılır.
4. Dosya yeniden okunur; bit-exact real64 state karşılaştırılır.
5. Aynı state'ten %100 yüke devam edilir.
6. Final displacement uninterrupted reference ile karşılaştırılır.

## Corruption checks

- truncated file reddedilir,
- yapısal olarak tamamlanmış fakat checksum'ı değiştirilmiş file reddedilir,
- failed read partial active state bırakmaz.
