# VER-V120-004 — Native OCCT STEP Box Import

Bu test yalnız OpenCASCADE bulunan build'de derlenir.

1. OCCT `BRepPrimAPI_MakeBox(10,20,30)` oluşturur.
2. `STEPControl_Writer` ile geçici STEP dosyasına yazar.
3. FEMCAE `OcctStepImporter` XDE/STEPCAF üzerinden tekrar import eder.
4. En az bir body ve tam 6 face beklenir.
5. İlk body display tessellation'a çevrilir; point/triangle listeleri boş olmamalıdır.

macOS CI `FEMCAE_REQUIRE_OCCT=ON` kullandığından bu test native CAD release gate'idir.
