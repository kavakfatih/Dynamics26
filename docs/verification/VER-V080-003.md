# VER-V080-003 — Nonlinear Checkpoint / Restart

## Amaç

Bir nonlinear çözümün son converged load state'inden kesintisiz continuation yapabildiğini doğrulamak.

## Prosedür

1. Initial increment `0.25`.
2. `max_step_attempts=1` ile ilk %25 load step converge ettirilir ve çözüm bilinçli olarak tamamlanmadan durdurulur.
3. Result'tan `nonlinear_checkpoint_t` capture edilir.
4. Aynı model `initial_checkpoint` ile yeniden çözülür.
5. Solver kalan load interval'ini %100'e taşır.

## Acceptance

- checkpoint load factor = 0.25,
- checkpoint displacement last committed state'tir,
- restarted analysis completed load factor = 1,
- final displacement analitik finite-stretch çözümüyle uyuşur,
- accepted step counter continuation semantics'ini korur.

## Sınır

Bu verification in-memory checkpoint'i doğrular; durable restart file schema değildir.
