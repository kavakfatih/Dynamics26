# VER-V010-001 — Axial Bar Algebraic Baseline

## Amac

V0.1.0 verification altyapisini analitik sonucu bilinen en basit yapisal denklemle dogrulamak.

Bu test **BAR2 FEM elementi degildir**.

## Problem

\[
K = \frac{EA}{L}
\begin{bmatrix}
1 & -1\\
-1 & 1
\end{bmatrix}
\]

Sinir kosulu:

\[
u_1=0
\]

Yuk:

\[
f_2=F
\]

Beklenen:

\[
u_2=\frac{FL}{EA}
\]

## Kullanilan sayilar

- `E = 210000 MPa = N/mm^2`
- `A = 100 mm^2`
- `L = 1000 mm`
- `F = 21000 N`

Dolayisiyla:

\[
u_2=1\;mm
\]

Mesnet reaksiyonu isaret convention'ina gore `-21000 N` beklenir.

## Tolerans

Displacement absolute tolerance: `1e-12 mm`.

Bu verification V0.3/V0.5'te gercek BAR2 element verification'i ile tamamlanacaktir.
