# VER-V090-008 — Ogden Near-Repeated Principal Stretch

## Amaç
Ogden spectral tangent'in birbirine çok yakın principal stretch'lerde kararlı kalmasını ve çok-terimli signed `mu_i` kullanımını doğrulamak.

## Malzeme
İki terimli Ogden:

```text
mu = [ +2.4 MPa, -0.7 MPa ]
alpha = [ 1.7, -2.4 ]
sum(mu) > 0
```

İlk iki principal stretch yaklaşık eşit seçilir; böylece repeated-eigenvalue limit dalı zorlanır.

## Referans
Analytic `dS/dE`, central finite-difference Jacobian ile karşılaştırılır.

## Kabul
Relative error `< 1e-4` ve tangent symmetry kontrolü.
