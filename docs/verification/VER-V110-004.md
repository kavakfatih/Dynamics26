# VER-V110-004 — Failed-Step Contact Rollback

## Amaç

Path-dependent augmented-Lagrangian contact history'nin başarısız nonlinear increment tarafından commit edilemediğini doğrulamak.

## Senaryo

- yüksek yük ile augmented-Lagrangian contact model kurulur,
- maximum Newton iteration bilinçli olarak `1` yapılır,
- minimum increment cutback'i engelleyecek kadar büyük seçilir,
- nonlinear failure beklenir.

## Kabul kriteri

Her slave contact point için failed solve sonrası:

```text
committed_normal_multiplier = 0
trial_normal_multiplier     = 0
```

olmalıdır.

## Sonuç

`PASS VER-V110-004 contact rollback semantics`
