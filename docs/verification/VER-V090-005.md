# VER-V090-005 — Hyperelastic Newton Target Stretch

## Amaç
Constitutive → TL-HEX8 → global assembly → V0.8 Newton zincirinin gerçek hyperelastic equilibrium state'i yeniden üretmesini doğrulamak.

## Model
Tek HEX8, Neo-Hookean material. Y/Z DOF'ları kilitli, sol yüz X yönünde sabit. Hedef `lambda=1.08` için material-point response'tan PK1 `P11` hesaplanıp sağ yüze eşdeğer nodal force uygulanır.

Beklenen:

\[
u_x=(\lambda-1)L
\]

## Kabul
Newton converged ve sağ yüz ortalama X displacement analitik hedefle tolerance içinde eşleşir.
