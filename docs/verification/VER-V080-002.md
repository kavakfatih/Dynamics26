# VER-V080-002 — Modified Newton Equilibrium Verification

## Amaç

Modified Newton yönteminin aynı homogeneous finite-stretch probleminde Full Newton ile aynı equilibrium state'e ulaşmasını doğrulamak.

## Yöntem

- `NONLINEAR_MODIFIED_NEWTON`,
- sabit load increment baseline,
- step içinde ilk tangent sabit,
- aynı StVK analytical target force.

## Acceptance

- full load factor'a ulaşılmalı,
- tip displacement analitik finite-stretch değeriyle uyuşmalı,
- residual convergence sağlanmalı,
- solver state step sonunda commit edilmiş olmalı.
