# VER-V070-001 — Pure Rigid Rotation Objectivity

## Amaç

Finite rotation altında Green-Lagrange strain'in yapay gerinim üretmediğini doğrulamak.

## Problem

Unit HEX8 current configuration'ı reference cube'un `z` ekseni etrafında sonlu açıyla rigid rotation'ıdır.

\[
\mathbf{F}=\mathbf{Q},\qquad \mathbf{Q}^T\mathbf{Q}=\mathbf{I}
\]

Beklenen:

\[
\mathbf{E}=0,\quad \mathbf{S}=0,\quad \mathbf{f}_{int}=0,\quad J=1
\]

## Gate

Tüm Gauss noktalarında strain/stress ve element internal force numerical tolerance içinde sıfır olmalıdır.
