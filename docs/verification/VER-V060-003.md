# VER-V060-003 — Free-Free Axial Zero/Rigid Mode Detection

## Amaç

V0.6 roadmap'teki rigid-body mode detection maddesini assembled model seviyesinde doğrulamak.

## Model

- 1 adet TRUSS2
- iki uç axial yönde serbest
- transverse `y/z` DOF'lar yalnız formulation mekanizması oluşturmaması için constraint'li
- `E = 70 GPa`
- `ρ = 2700 kg/m³`
- `A = 2e-4 m²`
- `L = 1.5 m`
- consistent mass

Bu active axial sistemin stiffness matrix'i rank 1, nullity 1'dir. Nullspace mode iki node'un birlikte axial translation'ıdır.

## Beklenen sonuç

Zero/rigid mode count:

```text
1
```

Tek pozitif flexible eigenvalue:

```text
λ = 12 E / (ρ L²)
```

## Acceptance

- modal solve başarılı,
- `zero_mode_count == 1`,
- ilk pozitif eigenvalue analitik değerle tolerans içinde,
- modal residual `< 1e-10`.

## Not

Genel bir modelde stiffness nullity yalnız gerçek rigid-body modes'u değil, eksik constraint veya formulation mekanizmalarını da içerebilir. Bu nedenle engine metadata'sı `zero_mode_count` adını kullanır.

## Sonuç

Portable Debug/Release validation'da PASS.
