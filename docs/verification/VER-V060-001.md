# VER-V060-001 — Two-Element Axial Modal Verification

## Amaç

Global stiffness ve consistent mass assembly, generalized eigen solve, frequency dönüşümü, full-DOF mode reconstruction ve residual kontrolünü tek bir problemde doğrulamak.

## Model

- 3 node
- 2 adet eşit TRUSS2
- sol node sabit
- yalnız axial active DOF
- `E = 210 GPa`
- `ρ = 7800 kg/m³`
- `A = 1e-4 m²`
- her element `L_e = 1 m`

Persistent ID'ler array sırasından kasıtlı olarak farklıdır:

```text
Node IDs    = 100, 7, 900
Element IDs = 50, 10
```

## Referans

İki elemanlı ayrık FE modelin generalized eigenproblem'inin kapalı-form eigenvalue'ları:

```text
λ1 = (E/ρ) (30 - 18√2) / 7
λ2 = (E/ρ) (30 + 18√2) / 7
```

## Acceptance

- solver status başarılı,
- `λ1`, `λ2` analitik ayrık FE referansla tolerans içinde,
- modal residual maksimumu `< 1e-10`,
- mode'lar mass-normalized.

## Sonuç

Portable Debug/Release validation'da PASS.
