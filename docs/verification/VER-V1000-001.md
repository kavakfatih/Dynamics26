# VER-V1000-001 — HEX8 Cantilever Mesh Convergence

## Amaç

Structured linear HEX8 çözümünün mesh refinement ile bağımsız Euler–Bernoulli cantilever referansına yaklaştığını doğrulamak.

## Referans

Tip deplasmanı:

\[
\delta = \frac{F L^3}{3 E I}
\]

## Sonuç

| Mesh | Eleman | FE tip displacement | Relative error |
|---|---:|---:|---:|
| 4×1×1 | 4 | -0.169935 | 0.336192 |
| 8×2×2 | 32 | -0.228258 | 0.108368 |
| 12×3×3 | 108 | -0.245923 | 0.0393645 |

Acceptance:

- error sequence monotonically azalır,
- fine mesh relative error < 0.05,
- reaction equilibrium korunur.

Portable Debug ve Release: PASS.
