# VER-V070-005 — Finite Uniaxial Stretch

## Amaç

Finite stretch altında `E → S → σ` zincirini analitik StVK referansla doğrulamak.

\[
\mathbf{F}=\mathrm{diag}(\Lambda,1,1)
\]

\[
E_{11}=\frac12(\Lambda^2-1)
\]

StVK:

\[
S_{11}=(\lambda+2G)E_{11}
\]

\[
S_{22}=S_{33}=\lambda E_{11}
\]

ve `J=Λ` için:

\[
\sigma_{11}=\Lambda S_{11}
\]

\[
\sigma_{22}=S_{22}/\Lambda
\]

Element Gauss-point sonuçları bu kapalı-form değerlerle karşılaştırılır.
