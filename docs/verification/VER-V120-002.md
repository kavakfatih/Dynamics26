# VER-V120-002 — Hollow Rectangle Section

Outer `0.100 x 0.060 m`, inner hole `0.080 x 0.040 m` aynı vertex orientation ile verilir. Hole fiziksel flag'i signed contribution'ı belirler.

```text
A = bo*ho - bi*hi
Ixx = (bo*ho^3 - bi*hi^3)/12
Iyy = (ho*bo^3 - hi*bi^3)/12
```

Bu test hole subtraction ve centroidal inertia hesabını doğrular.
