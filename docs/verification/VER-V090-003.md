# VER-V090-003 — J2 Consistent Algorithmic Tangent

## Amaç
Plastic return-map response'un analytic algorithmic tangent'ini aynı committed state'ten başlayan central finite-difference stress Jacobian ile karşılaştırmak.

## Malzeme
`E=210 GPa`, `nu=0.3`, `sigma_y0=250 MPa`, `H=1.5 GPa`.

## Kritik sözleşme
FD artı/eksi pertürbasyonlarının her biri **aynı committed state**'ten başlamalıdır; base trial state'in plastic update'i referans state'e sızdırılmaz.

## Kabul
Relative tangent error `< 5e-5`.
