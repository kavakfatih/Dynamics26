# VER-V130-002 — Native OCCT STEP Box → Geometry → HEX8 Provenance

## Gate

Bu test yalnız OCCT etkin native build'de çalışır. Portable Linux stub sonucu native STEP doğrulaması olarak sayılmaz.

## Amaç

Gerçek STEP B-Rep topolojisinin structured solver mesh provenance'ına bağlanmasını doğrulamak.

## Zincir

```text
OCCT BRepPrimAPI_MakeBox
 -> STEP write
 -> STEPCAF/XDE import
 -> GeometryDocument
 -> axisAlignedBoxDescriptor
 -> body bounds + six CAD face IDs
 -> StructuredHexMesher
 -> boundary MeshFacet.sourceGeometryId
```

## Kontroller

- imported body mevcut,
- axis-aligned descriptor üretilebilir,
- altı yön için ayrı CAD face ID bulunur,
- structured HEX8 mesh body provenance taşır,
- boundary facet'ler doğru face ID'lerine bağlanır,
- mesh `sourceGeometryRevision` imported document revision ile eşleşir.

## Sınır

Bu verification arbitrary curved STEP body için general-purpose volume meshing iddiası değildir.
