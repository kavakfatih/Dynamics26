# Dynamics26 V1.1.0-beta.2 — Solver / Convergence Workspace Plan

## 1. Amaç

Beta.2'nin amacı mevcut solver çekirdeğinde üretilen çözüm ve yakınsama bilgisini profesyonel bir engineering utility workspace'e taşımaktır.

Roadmap kapsamı:

- load step,
- Newton iteration,
- residual,
- displacement increment,
- line search,
- cutback / growth,
- contact state,
- convergence warnings,
- solver controls.

Beta.2 yeni nonlinear matematik icat etmez. Önce mevcut authoritative solver telemetry kullanılır; eksik integration katmanları açıkça ayrı paketlerde tamamlanır.

## 2. Source-of-truth sınırı

Beta.2 başlangıcında repository gerçeği:

- GUI milestone: `V1.1.0-beta.1`,
- engineering core baseline: `V1.0.2`,
- `fem_nonlinear_solver` zaten Newton/adaptive stepping/line-search ve history üretir,
- `nonlinear_history_entry_t` attempt, iteration, load factor, residual, displacement increment, line-search alpha ve ek nonlinear/contact metriklerini taşır,
- C ABI nonlinear verification preset'i history dizilerinin temel subset'ini dışarı verir,
- Utility Workspace'te `Convergence` tabı vardır,
- nonlinear verification preset'i mevcut Convergence tabına veri yazmaktadır,
- general `AnalysisService::solve()` ise halen `fem_solve_linear_hex8_mesh` ile linear Static Structural çözüm kullanır.

Bu nedenle Beta.2 başlangıcında general model solve için gerçek Newton stream varmış gibi ikinci/fake telemetry üretilmez.

## 3. Mimari kural

```text
Solver authoritative state / history
        ↓
C ABI / application solve boundary
        ↓
Typed Solver Telemetry DTO
        ↓
Utility Workspace presentation
```

Kurallar:

- widget engineering/solver state'in sahibi değildir,
- convergence verisi document state değildir ve Undo stack'e girmez,
- string-list tablo satırları canonical telemetry modeli değildir,
- solver algoritması ile GUI presentation birbirine doğrudan bağlanmaz,
- unsupported/unavailable metric `0` gibi sahte bir mühendislik değeriyle gösterilmez,
- general linear solve için Newton iteration uydurulmaz,
- Contact solver consumer mevcut değilken model Contact telemetry varmış gibi gösterilmez.

## 4. Paketler

### B2.1 — Typed Convergence Telemetry Foundation

Hedef:

- typed convergence row/session DTO,
- Utility Workspace typed binding,
- stable object names,
- session summary,
- legacy string-row API'nin geçici compatibility yolu,
- derived telemetry'nin document Undo üretmediğinin acceptance testi.

Bu paket solver core'u değiştirmez.

### B2.2 — Existing Nonlinear Verification Telemetry Migration

Hedef:

- `fem_demo_nonlinear_hex8` history çıktısını typed telemetry contract'ına taşımak,
- final residual / accepted steps / total iterations / cutback summary göstermek,
- legacy `QVector<QStringList>` producer kullanımını kaldırmak,
- verification sonucu ile Convergence tablosu arasında exact row acceptance kurmak.

### B2.3 — Solver Controls Authoring

Hedef:

- Basic / Advanced ayrımı,
- nonlinear method intent,
- max iterations,
- adaptive stepping,
- initial/min/max increment,
- line search,
- convergence tolerance ayarları için authoritative model state,
- canonical document commands,
- Undo/Redo,
- persistence,
- Preflight validation.

General model solver'ın gerçekten tüketmediği kontrol kullanıcıya aktifmiş gibi sunulmaz.

### B2.4 — Model Solve Telemetry Integration

Hedef:

- `AnalysisService` solve session ile typed telemetry contract'ını bağlamak,
- linear solve için doğru summary (`Direct solve`, Newton history yok),
- nonlinear model solve consumer bağlandığında aynı contract üzerinden Newton history,
- stale/result lifecycle ile solve session lifecycle ayrımı.

Bu paket general nonlinear model solve consumer'ın gerçek durumuna göre ilerler; demo kernel varlığı model solve desteği olarak sayılmaz.

### B2.5 — Convergence Diagnostics & Advanced Metrics

Hedef:

- residual / displacement criterion state,
- load increment ve adaptive growth/cutback olayları,
- line-search alpha,
- minimum `J`,
- mixed `u-p` pressure residual/increment,
- Contact consumer gerçekten bağlandıktan sonra active/stick/slip/penetration telemetry,
- warning/failed-step presentation.

Unsupported metric açıkça `Unavailable` kalır.

### B2.6 — Beta.2 Closeout

Kapanış gate'leri:

- application acceptance,
- solver/core regression,
- trusted Apple Silicon native validation,
- Light/Dark UI audit,
- accessibility / keyboard navigation,
- source/docs milestone consistency.

Milestone ancak bu zincir tamamlandıktan sonra:

```text
DYNAMICS26_GUI_MILESTONE="1.1.0-beta.2"
```

değerine yükseltilir.

## 5. B2.1 acceptance kriterleri

B2.1 tamamlanmış sayılmak için:

1. typed telemetry row/session yapısı `CODE EXISTS`,
2. Convergence tabı typed snapshot kabul eder,
3. session summary gerçek metrikleri gösterir,
4. iteration tablosu typed row'ları deterministik render eder,
5. telemetry update document Undo count'ını değiştirmez,
6. table/summary için stable objectName vardır,
7. empty snapshot stale eski satır bırakmaz,
8. automated application acceptance PASS olur,
9. existing nonlinear verification ve diğer GUI acceptance zinciri regress olmaz.

## 6. Bilinçli ertelenenler

B2.1 kapsamında değildir:

- asynchronous solver job architecture,
- gerçek zamanlı per-iteration callback ABI,
- solve cancel/interrupt,
- general Static Structural nonlinear solve consumer,
- general model Contact solver consumer,
- Beta.2 milestone bump.

Bu özellikler yalnız gerçek source capability oluşturulduğunda `FEATURE WORKS` olarak sınıflandırılır.
