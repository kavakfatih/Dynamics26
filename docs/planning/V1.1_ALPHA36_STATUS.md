# Dynamics26 V1.1.0-alpha.3.6 — Implementation Status

## Scope

Alpha.3.6, Named Selection'ı saved raw ID listesi olarak değil, model graph üzerinde yaşayan reusable persistent engineering scope olarak ele alır.

## Source state

Source GUI milestone, functional + native visual acceptance tamamlandıktan sonra `1.1.0-alpha.3.6` değerine yükseltilmiştir. Fiziksel mouse/trackpad kabulü ayrı `USER VALIDATED` katmanı olarak izlenmeye devam eder.

### Uygulanan davranışlar

- `NamedSelectionService` persistent `ScopeReference` CRUD ve exact 64-bit persistence.
- Geometry scope için runtime revision + stable CAD engineering identity doğrulaması.
- Mesh scope için generation stale guard; numeric ID yeniden görünse bile silent rebind yok.
- Mixed domain ve mixed entity-kind scope reddi.
- `Edit Selection → Apply Selection / Cancel` transaction workflow'u.
- Valid stored scope edit başında güvenli transient preload; stale scope için sıfır old-ID preload.
- Normal Named Selection görünümünde stored scope'tan dinamik Geometry/Mesh context ve persistent overlay.
- Normal persistent overlay `SelectionManager` transient state'i değildir.
- Fixed Support / Force consumer'larında `NamedSelection ObjectId` reference; entity ID copy yok.
- Consumer preflight/dependency/solver resolution aynı authoritative scope resolver zincirini kullanır.
- Multi-face boundary presentation persistent resolver sonucu üzerinden çizilir; legacy tek-`BoxFace` fallback yoktur.
- Programatik `selectObject()` akışı Navigator `currentChanged → objectSelected` zincirini tek source of truth olarak kullanır; persistent Named Selection context'i ikinci shell dispatch ile ezilmez.

## Acceptance contract

```text
Persistent Named Selection
        ↓ validate current provenance
Valid? ──────────────── No
  │                    │
  │                    └─ OutOfDate/Error; old IDs not displayed
  ↓
Normal View: persistent overlay only
  │
Edit Selection
  ↓
Transient SelectionManager state
  ↓
Apply = one Undo command
Cancel = no document mutation
```
