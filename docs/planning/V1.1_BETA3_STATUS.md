## B3.0 research / design record

### Problem

`AnalysisService::preflight()` engineering validation için doğru authoritative
boundary'dir; fakat analysis, material, formulation, kinematics, contact ve
backend support kararları doğrudan `if` bloklarına dağılmıştır. Bu durum Solve
içinde ikinci/gizli applicability kuralları oluşması riskini taşır.

### Adopt / adapt / reject

- **Adopt:** capability'yi typed axis + state ile çözmek.
- **Adapt:** ANSYS/COMSOL applicability yaklaşımını Dynamics26 document/service
  sınırlarına uyarlamak.
- **Keep:** `AnalysisService::preflight()` tek kullanıcı-facing engineering
  validation source olarak kalır.
- **Reject:** ikinci bağımsız validator ve Solve içinde capability tekrarları.

### Typed states

`Ready`, `SetupOnly`, `Unavailable`, `Stale`, `Invalid`.

### Evaluated axes

Analysis Type, Geometry Source, Mesh Topology, Element Formulation, Material
Model, Kinematics, Incompressibility/Formulation, Boundary Condition, Load Type,
Contact, Linear Backend, Nonlinear Algorithm ve Requested Result Field.

### Matrix metadata baseline

Displacement-only HEX8 için `symmetric / SPD expected`; mixed `u-p` için
`symmetric / indefinite`; active contact kombinasyonu için conservative
`unsymmetric / definiteness unknown` metadata üretilir. Current product backend
`dense reference` olarak doğru adla raporlanır; CG indefinite/unsymmetric sistemde
generic fallback değildir.

## B3.1 audit / design record

- `SelectionCoordinator` içindeki mevcut context-menu yolu doğru persistent
  relationship'i kuruyordu; ancak lambda doğrudan application acceptance altında
  değildi.
- Quick-authoring davranışı `createBoundaryConditionFromCurrentFaceSelection()`
  olarak tek canonical application method'una çıkarıldı. Context menu ve test aynı
  method'u tüketir.
- Method yalnız current, homogeneous `Geometry/Face` scope kabul eder. Mesh domain,
  yanlış kind ve stale CAD revision document mutation oluşturmadan reddedilir.
- Named Selection ve Fixed Support/Force ayrı domain command olarak korunur, fakat
  tek `QUndoStack` macro'sunda bir engineering transaction oluşturur.
- Pozitif CAD acceptance sahte topology ID üretmez. OCCT topology workflow'unun
  oluşturduğu gerçek STEP kutusunda one/multi Face, Undo/Redo ve project
  save/reopen ObjectId bütünlüğünü doğrular.

## B3.2 research / design record

- `SimulationMesh::boundaryFacets` QUAD4 node ordering'i ve
  `sourceGeometryId` CAD Face provenance'ı solver input için yeterlidir; display
  tessellation veya glyph state kullanılmaz.
- Seçili bütün Face/facet'lerin reference alanı önce 2×2 Gauss quadrature ile
  tek kez toplanır. Sonra tek `t_ref = F_total / A_ref` traction aynı quadrature
  noktalarında `N^T t_ref` ile nodal vektörlere entegre edilir.
- Axis-aligned kutu için `A/4` hard-code edilmez. Bilinear ve warped QUAD4 mapping
  `|dX/dξ × dX/dη|` surface Jacobian'ını kullanır.
- Assembler Qt'den bağımsız `femcae_meshing` katmanındadır. Preflight aynı
  assembly'yi doğrular; Solve eşit node paylaşımı yapmaz.
- Deterministic tests X/Y/Z resultant, reference-point moment, 1/2/4 refinement,
  multi-Face single-resultant, unequal-area facets, warped QUAD4 ve missing-node
  failure davranışlarını kapsar.

## B3.3 audit / design record

- Eski `AnalysisService::solve()` preflight sonrasında da canlı `MeshService`,
  `MaterialService` ve boundary definition nesnelerinden C dizileri kuruyordu.
- Yeni `AnalysisSnapshot` API/schema v1; SI node coordinates, HEX8 connectivity,
  element/formulation + material assignment, material constants, constraints,
  B3.2'de assemble edilmiş equivalent nodal loads, nonlinear controls, linear
  matrix/backend metadata ve requested results alanlarını owning value olarak taşır.
- `AnalysisSnapshotBuilder` feature applicability kararı vermez; aynı resolved
  capability'nin ardından yalnız veri bütünlüğü/invariant doğrular. Böylece
  authoritative engineering validator `AnalysisService::preflight()` kalır.
- `SolverInputBuilder` snapshot'ı C ABI array+count düzenine flatten eder;
  overlapping identical constraints'i canonicalize eder, çelişen prescribed
  değerleri reddeder ve birden çok load contribution'ını node/component bazında
  deterministic toplar.
- Current linear product consumer da snapshot sınırına taşındı. Snapshot
  oluşturulduktan sonra solve ve result mapping canlı GUI/service input state'i
  okumaz. Nonlinear snapshot'ın DirectLinear consumer'a düşmesi explicit guard
  ile yasaktır; B3.4/B3.5 general nonlinear consumer bağlanana kadar resolver
  `SetupOnly` üretmeye devam eder.

## B3.4 audit / design record

- `fem_demo_nonlinear_hex8*` entry point'leri gizli tek-element geometri kuran
  verification preset'leridir; product API olarak yeniden kullanılmadı ve mevcut
  imzaları değiştirilmedi.
- Additive `fem_solve_nonlinear_static_hex8_v1()` yalnız caller-supplied Node ID,
  SI coordinate, arbitrary HEX8 connectivity, nodal constraint/load ve nonlinear
  control dizilerini kabul eder. Fortran private derived type ABI dışına çıkmaz;
  array+count ownership ve API version sözleşmesi public header'da açıktır.
- Product yol yeni Newton implementasyonu içermez. Mevcut
  `solve_nonlinear_static()` Full/Modified Newton, adaptive stepping, cutback,
  growth ve line-search altyapısı doğrudan tüketilir. Beta.3 ABI yalnız
  `Dense Reference` backend ID'sini kabul eder; başka ID için fallback yapmaz.
- Final displacement active equation çözümü ile prescribed DOF'ların tam nodal
  alanıdır. Reaction, final Total-Lagrangian element internal force'larının tüm
  DOF'larda yeniden assembly edilmesi ve constrained DOF'larda
  `R = f_int - f_ext` dengesiyle recover edilir.
- Equivalent Stress tanımı element başına sekiz Gauss noktasındaki final Cauchy
  von Mises değerlerinin aritmetik ortalamasıdır. Bu ölçü StVK'nin Second
  Piola-Kirchhoff constitutive hesabından current Cauchy stress'e dönüştürülür.
- Telemetry buffer caller-owned'dır. `history_count` yazılan kayıt sayısını,
  `history_required_count` tam history boyutunu taşır; kapasite yetersizliği
  sessiz veri varsayımı yerine explicit truncation metadata üretir.
- C ABI acceptance iki arbitrary HEX8, non-sequential persistent ID'ler, reaction
  equilibrium, positive minimum J, finite displacement/stress, Full/Modified
  Newton equilibrium eşdeğerliği, line-search on/off eşdeğerliği, history
  truncation ve unsupported backend rejection kontrollerini kapsar.
- Meshing/API integration acceptance, StructuredHexMesher'ın 1/2/4 axial
  refinement seviyelerini aynı general ABI'de çözer; surface resultant/reaction
  dengesini ve global uç deplasman cevabının stabilizasyonunu doğrular.
- Hosted macOS arm64 build/verification run `33781193826` başarıyla tamamlandı.

## B3.5–B3.7 audit / design record

- `NonlinearHex8SolverBridge` yalnız immutable, owning `Hex8SolverInput` okur;
  canlı document, mesh, selection veya widget nesnesi solver sınırına geçmez.
- `AnalysisService::solve()` analysis kind'a göre açıkça ayrılır: linear snapshot
  mevcut linear ABI'ye, nonlinear snapshot general nonlinear v1 ABI'ye gider.
  Geçersiz formulation/backend/method bridge'de reddedilir; Full Newton veya
  DirectLinear'a sessiz fallback yoktur.
- Existing Beta.2 typed telemetry korunur. Product ABI'nin attempt, accepted step,
  iteration, load factor/increment, residual/displacement normları, relative
  criteria, line-search alpha, minimum J ve converged alanları doğrudan map edilir.
  Pressure/contact alanları değer uydurulmadan `Unavailable` kalır.
- Application acceptance gerçek `Dynamics26MainWindow` composition'ında
  Nonlinear Static oluşturur; large deformation ve Full Newton/adaptive/line-search
  controls author eder; CAD topology gate'inde gerçek Face seçimini persistent
  Named Selection üzerinden Fixed Support/Total Force'a bağlar.
- Aynı akış eksik support/load için authoritative Preflight rejection ve document
  immutability, project save/reopen ObjectId bütünlüğü, regenerated mesh sonrası
  Solve readiness, final nonlinear fields, Newton history, positive minimum J ve
  reaction/resultant dengesini doğrular. Derived field/history project JSON'a
  yazılmaz; reopened authoring model yeniden Solve-ready olur.
