# Dynamics26 V1.1.0 — GUI / UI / UX Araştırma ve Uygulama Planı

**Durum:** Onaylı çalışma planı  
**Engineering core tabanı:** V1.0.2  
**Güncel source GUI milestone:** **V1.1.0-alpha.3.5**  
**Aktif sonraki milestone:** **V1.1.0-alpha.3.6 — Named Selection + Persistent Scope Workflow**  
**Amaç:** Mevcut engineering/debug GUI'yi profesyonel, macOS-first CAE kullanıcı deneyimine dönüştürmek.  

## 1. Ürün hedefi

V1.1.0'ın ana amacı yeni solver fiziği eklemek değil; mevcut CAD, meshing, material, load/BC, nonlinear, mixed `u-p`, contact ve results altyapısını gerçek bir mühendislik workflow'una bağlamaktır.

Hedef kullanıcı akışı:

```text
New Project
   ↓
Geometry
   ↓
Materials / Sections
   ↓
Connections
   ↓
Mesh
   ↓
Analysis
   ↓
Loads / Boundary Conditions
   ↓
Preflight
   ↓
Solve
   ↓
Results
```

Başarı kriteri yalnız modern görünüm değildir. Kullanıcı:

- neyi seçtiğini,
- hangi project object üzerinde çalıştığını,
- scope'un hangi engineering entity'lere bağlı olduğunu,
- modelin neden stale/invalid olduğunu,
- solve öncesi hangi eksiklerin bulunduğunu

açıkça anlayabilmelidir.

## 2. Temel tasarım ilkeleri

Dynamics26 tek bir rakip CAE uygulamasını görsel olarak kopyalamaz. Profesyonel interaction pattern'leri araştırılır ve Dynamics26 mimarisine uyarlanır.

Ana ilkeler:

- viewport birincil çalışma alanıdır,
- sol panel Project Navigator'dır; komut listesi değildir,
- sağ panel contextual Inspector'dır,
- bottom utility alanı gerektiğinde açılan diagnostics/solve/results çalışma alanıdır,
- context toolbar yalnız aktif workflow için gerekli araçları gösterir,
- Basic / Advanced seçenekler ayrılır,
- engineering identity ile display identity karıştırılmaz,
- focus / hover / selection / project current object / persistent scope ayrı state'lerdir,
- sistem Light/Dark görünümü native Qt/macOS paleti üzerinden izlenir,
- el yazımı global QSS/palette override geri getirilmez.

## 5. Selection mimarisinin güncel durumu

Selection altyapısı V1.1 GUI'nin temel servislerinden biridir.

```text
Selection Filter / Policy
        ↓
Picking / Preselection
        ↓
Transient Current Selection
        ↓ Apply / Assign
Persistent Engineering Scope
```

### State ayrımı

- **Preselection:** hover candidate.
- **Current Selection:** seçilmiş engineering entity collection.
- **Primary Selection:** multi-selection içindeki current/anchor entity.
- **Project Current Object:** Navigator/Inspector aktif object.
- **Persistent Scope:** proje/model state'inde saklanan engineering reference.

Raw selection document Undo stack'ine girmez. Persistent model property/scope assignment ileride document command olarak undoable olabilir.

### Domain / kind modeli

```text
SelectionDomain
- ProjectObject
- Geometry
- Mesh

SelectionKind
- Object
- Body
- Face
- Edge
- Vertex
- Node
- Element
- Facet
```

## 6. Engineering identity kuralı

En kritik mimari invariant:

> **CAD Geometry != Display Tessellation != FEM Mesh**

Bu nedenle:

```text
CAD Face        != VTK triangle
CAD Edge        != display line
CAD Vertex      != display point
FEM Node        != VTK point index
FEM Element     != boundary VTK cell index
FEM Facet       != boundary VTK cell index
```

Display primitive yalnız provenance lookup anahtarıdır.

### CAD selection provenance

```text
OCCT Body / Face / Edge / Vertex
            ↓
Display provenance scene
            ↓
VTK hit
            ↓
GeometryEntityId
```

### FEM selection provenance

```text
SimulationMesh
  ├─ MeshNode.id
  ├─ MeshElement.id
  └─ MeshFacet.id / ownerElementId
            ↓
MeshSelectionScene
            ↓
VTK hit
            ↓
MeshEntityId
```

## 8. macOS pointer / keyboard contract

Genel selection davranışı:

| Interaction | Sonuç |
|---|---|
| Click | Replace |
| Shift + Click | Add |
| Command + Click | Toggle |
| Drag | Visible-only Window Replace |
| Shift + Drag | Visible-only Window Add |
| Command + Drag | Visible-only Window Toggle |
| Empty click | Clear |
| Empty Replace window | Clear |
| Esc | Clear |
| Secondary click selected entity | mevcut multi-selection korunur |
| Secondary click unselected entity | entity primary/current yapılır |

Qt/macOS notu:

- fiziksel **Command** → `Qt::ControlModifier`,
- fiziksel Control `Qt::MetaModifier` semantiğiyle gelebilir,
- `Qt::META` Command shortcut yerine kullanılmaz,
- Option/Alt selection modifier değildir.

Mesh selection aktifken plain selection gesture FEM bridge tarafından consume edilir. Alt+Left, Middle, wheel ve native camera gestures navigation'a geçer.
