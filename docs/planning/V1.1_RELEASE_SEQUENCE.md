Bu belge V1.1 GUI dönüşümünün güncel kilometre taşı sırasını ve doğrulama durumunu tanımlar. Ayrı feature/fix branch açılmaz; geliştirme doğrudan `main` üzerinde commit + version + CI kanıtı ile ilerler.

## 1. Kapanış terminolojisi

Bir özelliğin repository'de bulunması tek başına tamamlandığı anlamına gelmez. Dynamics26 için aşağıdaki durumlar birbirinden ayrılır:

```text
CODE EXISTS
TEST EXISTS
TEST PASSED
FEATURE WORKS
USER VALIDATED
```

- **CODE EXISTS:** kaynak kodu vardır.
- **TEST EXISTS:** davranışı doğrulayan otomatik test vardır.
- **TEST PASSED:** ilgili test güncel source üzerinde geçmiştir.
- **FEATURE WORKS:** uygulama seviyesindeki composition / interaction zinciri otomatik olarak doğrulanmıştır.
- **USER VALIDATED:** gerçek macOS cihazında kullanıcı mouse/trackpad, görünürlük ve workflow davranışını kabul etmiştir.

Özellikle fiziksel mouse/trackpad ve Light/Dark görsel kabulü yalnız otomatik CI ile `USER VALIDATED` sayılmaz.

## 3. Korunan mimari kurallar

V1.1 GUI çalışmaları aşağıdaki ürün mimarisini değiştirmez:

- Modern Fortran solver core,
- C ABI,
- C++20 geometry / meshing,
- Qt 6 GUI,
- VTK viewport,
- OCCT CAD topology,
- CMake / Ninja / CTest,
- macOS / Apple Silicon ürün hedefi.

En kritik geometri kuralı:

> **CAD Geometry != Display Tessellation != FEM Mesh**

Buna göre:

- display triangle CAD Face değildir,
- display line CAD Edge değildir,
- display point CAD Vertex veya FEM Node değildir,
- VTK cell index FEM Element veya Facet ID değildir,
- seçim kimliği her zaman ilgili engineering domain'in gerçek ID'sinden çözülür.

## 4. V1.1.0-alpha.3.2 — CAD Body / Face Selection & Scoping Foundation

### Amaç

Geometry, Material, Mesh, BC, Load, Contact ve Results workflow'larının kullanacağı merkezi selection state ve persistent scope ayrımını kurmak.

### Tamamlanan temel kontratlar

```text
Selection Filter / Policy
        ↓
Picking / Preselection
        ↓
Transient Current Selection
        ↓ Apply / Assign
Persistent Engineering Scope
```

- `SelectionDomain` ayrımı: ProjectObject / Geometry / Mesh.
- `SelectionManager` transient selection sahibidir.
- Preselection, committed selection ve primary selection ayrıdır.
- `SelectionPolicy` active context tarafından izin verilen entity seviyesini belirler.
- raw selection `QUndoStack`'e girmez.
- `ScopeReference` transient selection'dan ayrıdır.
- CAD geometry revision stale-detection guard olarak kullanılır.
- Body / Face gerçek CAD topology kimlikleri üzerinden seçilir.
- display triangle → Face provenance açıkça korunur.
- Navigator / Viewport / Inspector synchronization kurulmuştur.

### macOS interaction kontratı

| Interaction | Selection sonucu |
|---|---|
| Click | Replace |
| Shift + Click | Add |
| Command + Click | Toggle |
| Empty click | Clear |
| Esc | Clear |
| Secondary click selected entity | Selection korunur |
| Secondary click unselected entity | Hit primary/current yapılır |

Qt/macOS'ta fiziksel Command semantiği `Qt::ControlModifier` ile ele alınır. `Qt::META` Command yerine kullanılmaz.

## 6. V1.1.0-alpha.3.4 — FEM Selection

### 6.1 Amaç

Generated `SimulationMesh` üzerinde gerçek FEM kimliklerine dayanan görünür entity selection kurmak.

Alpha.3.4 kullanıcı-visible kapsamı:

- **FEM Node** — görünür boundary node,
- **FEM Element** — görünür boundary üzerinden owner HEX8 element,
- **FEM Facet** — HEX8 boundary facet.

Bu sürümde interior/pick-through ve window/rectangle selection yoktur.

### 6.2 FEM provenance modeli

```text
SimulationMesh
   ├─ MeshNode.id
   ├─ MeshElement.id
   └─ MeshFacet.id + ownerElementId
            ↓
MeshSelectionScene
            ↓
VTK display primitive
            ↓
Picker hit
            ↓
MeshEntityId
```

Kurallar:

- VTK point/cell index yalnız lookup anahtarıdır.
- `MeshEntityId` ile display index aynı kimlik alanı değildir.
- boundary cell Facet mode'da `MeshFacet.id`, Element mode'da `ownerElementId` üretir.
- Node mode görünür boundary node provenance tablosundan gerçek `MeshNode.id` üretir.

### 6.3 Mesh lifecycle / stale selection

`MeshService::generation()` transient ve persistent FEM selection için lifecycle guard'dır.

```text
Mesh Generation N
      ↓
Node / Element / Facet Selection
      ↓
Persistent FEM Scope
      ↓
Mesh regenerate / clear / reset
      ↓
Generation N+1
      ↓
Old selection/scope = STALE
```

Numeric MeshEntityId yeni mesh'te tesadüfen aynı olsa bile eski scope otomatik rebind edilmez.

### 6.4 FEM persistent scope

`ScopeEntityReference` Mesh domain için gerçek `meshEntityId` taşır.

Persistent FEM scope:

- Node / Element / Facet kind,
- `MeshEntityId`,
- source mesh generation,
- multi-entity collection

taşır.

`buildMeshScopeReference()` ve `validateMeshScopeReference()`:

- stale generation,
- missing MeshEntityId,
- unsupported domain/kind
hatalarını açıkça ayırır.

### 6.5 Geometry / Mesh UI domain ayrımı

Selection toolbar context-aware'dır:

```text
Geometry context → Body | Face | Edge | Vertex
Mesh context     → Node | Element | Facet
Other contexts   → selection filter grubu gizli
```

FEM Node/Element/Facet project tree'de ayrı object değildir. Selection current project-object context'ini canonical **Mesh** node üzerinde tutar.

### 6.6 Selection / navigation event ownership

CAD ve FEM picker ayrı bridge'lerde tutulur:

- `ViewportSelectionBridge` → CAD topology,
- `ViewportMeshSelectionBridge` → FEM mesh.

Mesh context'te:

- plain Left selection gesture Mesh bridge tarafından consume edilir,
- Right context gesture Mesh bridge tarafından consume edilir,
- hover/preselection Mesh bridge tarafından consume edilir,
- Esc Mesh selection state'ini temizler,
- Alt+Left / Middle / wheel / native camera gestures navigation'a bırakılır.

Böylece aynı mouse release hem FEM picker'a hem legacy CAD/VTK pick callback'ine düşmez.

## 7. V1.1.0-alpha.3.5 — Visible-only Window / Area Selection

### 7.1 Amaç

Alpha.3.2–3.4 click-selection temelini viewport üzerinde gerçek rectangle/window selection'a genişletmek ve aynı transient `SelectionManager` semantiğini CAD ile FEM domain'lerinde korumak.

### 7.2 Tamamlanan kullanıcı-visible kapsam

- plain Left drag ile rectangle / window selection,
- drag sırasında native Qt `QRubberBand` görsel feedback,
- `vtkHardwareSelector` tabanlı GPU-backed area selection,
- **visible-only** selection policy,
- Geometry context'te:
  - Body / Face / Edge → VTK CELL association,
  - Vertex → VTK POINT association,
- Mesh context'te:
  - Node → VTK POINT association,
  - Element / Facet → VTK CELL association,
- click selection ile aynı Replace / Add / Toggle semantiği,
- Shift + drag → Add,
- fiziksel Command + drag (`Qt::ControlModifier`) → Toggle,
- empty Replace window → Clear,
- empty Add / Toggle window → no-op,
- Alt+Left / Middle / wheel / native camera gestures → navigation,
- window selection raw transient state olarak kalır; document `QUndoStack`'ine girmez.

`QRubberBand` yalnız interaction preview'dur; drag sırasında document veya engineering selection state'i mutate etmez. Selection commit yalnız pointer release sonrasında yapılır.

### 7.3 CAD / FEM provenance kontratı

CAD area selection:

```text
Screen Rectangle
      ↓
vtkHardwareSelector
      ↓
VTK CELL / POINT id
      ↓
GeometryTopologyScene provenance
      ↓
GeometryEntityId
```

FEM area selection:

```text
Screen Rectangle
      ↓
vtkHardwareSelector
      ↓
VTK CELL / POINT id
      ↓
MeshSelectionScene provenance
      ↓
MeshEntityId
```

Kurallar:

- VTK primitive ID engineering identity değildir.
- `GeometryEntityId` ve `MeshEntityId` yalnız provenance tablosu üzerinden çözülür.
- CAD ve FEM kimlik uzayları birbirine karıştırılmaz.
- Element mode'da bir HEX8'in birden fazla görünür boundary Facet'i area'ya düşse bile nihai engineering selection owner `MeshEntityId` üzerinden de-duplicate edilir.

### 7.4 Atomik batch selection

`SelectionManager::apply(batch, operation)` çoklu engineering entity setini tek transaction olarak uygular:

- identity de-duplication,
- Replace / Add / Toggle semantiği,
- stable primary selection,
- en fazla bir `selectionChanged` signal'i.

Window picker bridge'lerinin hit dizisi `SelectionCoordinator` içinde yeniden current Geometry/Mesh service state'ine karşı doğrulanır ve tek batch'e coalesce edilir. Böylece bir drag hareketi onlarca/yüzlerce ayrı application state transition üretmez.

Raw viewport selection yine document Undo/Redo history'sine girmez.

## 8. V1.1.0-alpha.3.6 — Named Selection + Reusable Scope Workflow

### 8.1 Amaç ve tamamlanan kapsam

Alpha.3.2–3.5 selection altyapısı document-level reusable engineering object'lerine bağlanmıştır. Alpha.3.6 kapanış kapsamı:

- model graph üzerinde kalıcı `NamedSelection` document object'leri,
- current transient selection'dan Named Selection oluşturma,
- Geometry ve Mesh domain'lerinde same-domain + same-kind scope collections,
- `ObjectId`, `GeometryEntityId`, `MeshEntityId`, revision/generation değerlerinde exact 64-bit persistence,
- `Edit Selection → Apply Selection / Cancel` transaction workflow'u,
- valid scope için güvenli transient preload,
- stale scope için sıfır old-ID preload ve açık reselect/repair akışı,
- normal görünümde transient selection'dan ayrı persistent viewport overlay,
- Geometry revision ve Mesh generation stale diagnostics,
- yalnız kontrollü project-load sırasında stable engineering identity doğrulamasıyla Geometry rebind; runtime auto-heal yok,
- Mesh generation için cross-session/runtime silent rebind yok,
- Fixed Support ve Force consumer'larında entity ID kopyalamak yerine Named Selection `ObjectId` referansı,
- consumer preflight / DependencyEngine / solver resolution için tek authoritative scope resolver,
- multi-Face boundary scope'ta FEM boundary node union + shared edge/corner de-duplication,
- Force toplam değerinin multi-Face scope üzerinde bir kez dağıtılması.

Named Selection transient selection'ın başka adı değildir; proje dosyasında yaşayan persistent engineering scope nesnesidir.
