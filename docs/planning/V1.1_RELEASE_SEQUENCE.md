## V1.1.0-alpha.1 — macOS Application Shell

Amaç, mevcut çalışan Qt/VTK/OCCT/C API/Fortran yollarını yeniden yazmadan sonraki bütün V1.1 çalışmalarını taşıyacak macOS-first pencere iskeletini oluşturmaktır.

### Kapsam

- kullanıcıya görünen uygulama kimliği `Dynamics26`,
- native `QMainWindow` / macOS window frame ve native traffic lights korunması,
- unified-titlebar hedefinin Qt/VTK `QOpenGLWidget` kısıtı nedeniyle güvenli native-window yaklaşımıyla uygulanması; unsupported Qt unified-toolbar flag'inin VTK aktifken zorlanmaması,
- document-title alanı (`Untitled.d26` başlangıç placeholder'ı),
- ana toolbar: Navigator toggle, document title, Search placeholder, Solve, Info,
- `Dynamics26 Context Bar` iskeleti,
- Context Bar ana alanları: Home, Geometry, Materials, Connections, Mesh, Physics, Analysis, Results,
- üçlü ana split: Navigator | VTK Viewport | Inspector,
- side panel show/hide altyapısı,
- bottom utility area iskeleti: Solver | Convergence | Graph | Table | Messages | Log,
- bottom utility alanının başlangıçta collapsed/hidden olması,
- macOS Menu Bar başlangıç yapısı,
- mevcut hard-coded light-only QSS yerine native/system palette kullanımı,
- Light/Dark Mode'un Qt/macOS sistem palette'i üzerinden doğal çalışması,
- mevcut solver, VTK, geometry, mesh ve project migration yollarının korunması.

### Bilinçli olarak kapsam dışı

- Navigator object modelinin yeniden yazılması — alpha.2,
- context command'ların gerçek command bus'a bağlanması — alpha.3,
- uçtan uca preflight/model validation — alpha.4,
- Basic/Advanced/Expert gerçek engineering inspectors — beta.1,
- Equation View — beta.1+,
- Material Calibration workspace — beta.1+,
- gerçek-time nonlinear convergence dashboard — beta.2,
- professional Results workspace — beta.3,
- internal/public `femcae_*`, `libfemcae`, `FEMCAE_*` ABI/CMake migration — ayrı compatibility audit sonrası,
- `.femcae.json` proje uzantısının `.d26`'ya kalıcı migration'ı — schema/file-association planı sonrası,
- `FEMCAE.app` internal bundle-path migration — release/deployment scripts birlikte taşınmadan yapılmaz.

### Acceptance criteria

1. Qt GUI kaynakları macOS/arm64 GUI job'unda derlenir.
2. Mevcut VTK viewport yolu kaybolmaz.
3. Mevcut geometry/mesh/material/analysis demo yolları compile-time olarak korunur.
4. Native bundle smoke ve strict Mach-O audit gevşetilmez.
5. Uygulama kullanıcıya `Dynamics26` adıyla görünür; solver/internal compatibility isimlerinin kalması açıkça belgelenir.
6. Main window üçlü split ve bottom utility mimarisini taşır.
7. Hard-coded yalnız-light-mode global style kaldırılır; system palette kullanılır.
8. Normal CI sonucu çalıştırılmadan PASS ilan edilmez.

Hedef workflow:

```text
New Project
→ Geometry
→ Materials / Sections
→ Connections
→ Mesh
→ Physics
→ Analysis
→ Loads / BC
→ Preflight
→ Solve
→ Results
```

Bu pakette model validation/preflight ana kabul kriteridir. Eksik material, empty scope, geçersiz contact pair ve analysis eksikleri solve öncesinde görünür olmalıdır.

## CI yaklaşımı

### Fast engineering GUI gate

Uygun olduğunda trusted/manual self-hosted MacBook runner kullanılabilir:

```text
Configure
→ incremental GUI/core build
→ core tests
→ GUI compile
→ GUI smoke / architecture checks
```

### Clean release/milestone gate

GitHub-hosted Apple Silicon temiz runner korunur:

```text
Clean configure
→ full build
→ full tests
→ install/deploy
→ bundle fixup
→ strict Mach-O audit
→ codesign
→ bundle smoke
→ artifact
```

Self-hosted runner hız içindir; clean GitHub-hosted runner reproducibility ve temiz-environment doğrulaması içindir. Strict bundle audit CI'yı geçirmek amacıyla gevşetilmez.
