# V1.1.0-beta.3 — Supported Nonlinear Workflow Vertical Slice

## Supported product envelope

Beta.3 solve target:

- parametric box or box-compatible STEP/CAD,
- current structured HEX8 mesher,
- verified finite-strain/total-Lagrangian product element path,
- Linear Elastic / StVK-like material path required by that formulation,
- Fixed Support,
- reference-area Total Force,
- Full / Modified Newton,
- adaptive stepping/cutback,
- line search,
- convergence telemetry,
- displacement/stress/reaction ResultSet.

Arbitrary STEP volume mesh, hyperelastic general product solve, mixed `u-p`, general Contact and follower pressure are not implicit Beta.3 capabilities.

## Critical work packages

1. **B3.0 Capability + Preflight contract**
   - setup-ready vs solve-ready,
   - supported combination descriptors,
   - no hidden fallback.
2. **B3.1 Selection/scope productivity**
   - multi-selection,
   - Named Selection/edit scope,
   - hide/show/isolate,
   - insert from selected Face.
3. **B3.2 Supports/Loads + surface integration**
   - Fixed Support,
   - Total Force,
   - Pressure capability state,
   - consistent face integration,
   - force/moment resultant tests,
   - glyph independence.
4. **B3.3 Material + Mesh readiness**
   - material assignment,
   - current structured HEX8 truth,
   - quality/stale diagnostics,
   - unsupported CAD blocking.
5. **B3.4 SolverInputSnapshot + product nonlinear C ABI**
   - immutable real-model input,
   - versioned/additive interface,
   - `solve_nonlinear_static()` routing.
6. **B3.5 Linear-backend suitability baseline**
   - dense reference guard,
   - matrix-property metadata,
   - no incompatible CG/mixed routing.
7. **B3.6 Convergence + ResultSet MVP**
   - accepted-state result dataset,
   - total/directional deformation,
   - equivalent stress,
   - reactions,
   - probe/min-max.
8. **B3.7 Vertical-slice acceptance**
   - deterministic benchmark,
   - save/reopen,
   - Undo/Redo,
   - failure/cancel,
   - native macOS UX.

## Main exit workflow

```text
New Project
→ box/box-compatible STEP
→ Material
→ Structured HEX8 Mesh
→ Nonlinear Static
→ Fixed Support from Face Selection
→ Total Force from Face Selection
→ Preflight Ready
→ Solve
→ Newton convergence
→ ResultSet
→ Save/Reopen
```

Beta.3 automated closeout is complete: the nonlinear solve is connected to the
real document/application composition and is not limited to verification helpers.

## Numerical acceptance

At minimum:

- target load factor reached,
- configured residual/displacement criteria satisfied,
- applied load and reaction equilibrium within documented benchmark tolerance,
- surface-force resultant conserved under mesh-density change,
- no NaN/Inf,
- invalid/negative-J state not silently accepted,
- no DirectLinear fallback,
- solver history reflects actual Newton iterations.

# V1.1.0-rc.1 — Workflow Hardening

**Current state:** TECHNICAL CLOSEOUT CANDIDATE. RC.1 release declaration and GUI
milestone bump remain blocked until exact-HEAD automated/native gates and physical
`USER VALIDATED` acceptance are complete. Automated success is not physical user
acceptance.

RC.1 cancellation contract is deliberately truthful: the current product solve
consumer is synchronous, therefore no active Cancel command is exposed. Cooperative
solver cancellation is deferred until a real safe cancellation boundary exists.

RC scope:

- all Beta.3 regressions green,
- real-device keyboard/mouse/trackpad acceptance,
- Light/Dark polish,
- project persistence/reopen,
- Cancel/failure recovery,
- stale geometry/mesh/result behavior,
- diagnostics wording/navigation,
- dense-reference size guard usability,
- native bundle/release audit,
- exact-head GUI/native acceptance ledger via `V1.1_RC1_STATUS.md`,
- capability matrix documentation,
- no unsupported feature leakage.

New material models or major new meshing algorithms are not RC objectives.
