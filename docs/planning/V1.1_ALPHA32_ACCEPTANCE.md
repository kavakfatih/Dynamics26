## 1. Closure rule

Alpha.3.2 is not considered fully user-validated merely because code builds or automated tests pass.
The milestone has two separate closure layers:

```text
CODE EXISTS
→ TEST EXISTS
→ TEST PASSED
→ ENGINEERING ACCEPTANCE PREVIEW
→ USER VALIDATED ON REAL macOS POINTER + APPEARANCE
```

This document records the state immediately before the real-device acceptance preview.
No stable tag/release is created at this stage.

## 2. Plan-review corrections completed before preview

A final review of the Alpha.3.2 technical plan found three gaps that were corrected before raising the GUI milestone:

1. **macOS modifier semantics:** physical Command must follow Qt's Apple-platform `ControlModifier` mapping. Physical Control / `MetaModifier` must not silently behave as Command Toggle.
2. **Real picker proof:** scene-level provenance tests alone were insufficient. A real offscreen `vtkCellPicker` regression was added to prove display-cell → CAD Body/Face provenance.
3. **Shell synchronization proof:** SelectionManager state alone was insufficient. A real application-composition acceptance path now verifies SelectionCoordinator → Navigator → Inspector synchronization and proves transient selection does not enter document Undo.

## 3. Automated evidence

### 3.1 Selection state, scope and input contract

Hosted Apple Silicon selection contract validates:

- Replace / Add / Toggle / Clear state transitions,
- stable primary selection,
- preselection separation,
- macOS Command mapping,
- physical Control not masquerading as Command,
- Option/navigation isolation,
- secondary-click click tolerance,
- persistent ScopeReference construction,
- geometry revision stale detection.

### 3.2 CAD topology and display provenance

Existing OCCT geometry verification plus the Alpha.3.2 selection tests prove:

- Body/Face IDs originate from CAD topology,
- Face parent Body identity is preserved,
- display triangle index is never treated as CAD Face identity,
- one CAD Face may own multiple display triangles,
- multi-body display scenes preserve independent Body/Face identities,
- stale geometry revision cannot generate a valid selection overlay.

### 3.3 VTK picker contract

Hosted run `33365821586` completed successfully on native arm64.
The offscreen regression uses a real `vtkCellPicker` and verifies:

```text
screen/display hit
→ VTK cell id
→ GeometrySelectionScene provenance
→ CAD Body / CAD Face identity
→ Body/Face filter result
→ multi-entity overlay cells
```

It also applies a numerical semantic-color guard for Selection and Preselection in Light and Dark palettes. This numerical guard is not presented as visual user acceptance.

### 3.4 Shell synchronization contract

Hosted run `33366265001` completed successfully on native arm64.
The `--selection-selftest` developer acceptance path verifies the real application composition:

- viewport-originated Body selection synchronizes Project Navigator current object,
- Inspector follows the owning project Body,
- Face selection keeps the parent Body as Navigator/Inspector context,
- Inspector exposes committed geometry selection as a secondary summary,
- Project ObjectId and CAD GeometryEntityId remain separate identity domains,
- Body/Face transient selection does not change the document `QUndoStack` index,
- the GUI executable is native arm64.

## 5. Engineering preview purpose

The Alpha.3.2 engineering preview is intentionally not a standalone distributable release.
It exists to close the remaining behavior that automation cannot truthfully certify:

- real mouse click / Shift-click / Command-click,
- empty-space clear,
- secondary-click behavior,
- middle-button / Shift-middle navigation collision,
- Option-left orbit collision,
- trackpad pan / pinch behavior,
- hover/preselection feel,
- Light Mode and Dark Mode visual readability,
- primary selection / multi-selection visual clarity.

Only after this real-device review can Alpha.3.2 be marked **USER VALIDATED** and the roadmap move cleanly to V1.1.0-alpha.3.3 — Topology + FEM Selection.

## 6. Explicit non-goals preserved

Alpha.3.2 still does not claim completion of:

- CAD Edge / Vertex selection,
- FEM Node / Element / Facet selection,
- box/rectangle selection,
- interior/pick-through selection,
- candidate cycling,
- Named Selection document objects,
- grow/shrink/connected/similar selection,
- BC/load/contact schema migration to ScopeReference.

Those remain assigned to Alpha.3.3 / Alpha.3.4 according to the V1.1 release sequence.
