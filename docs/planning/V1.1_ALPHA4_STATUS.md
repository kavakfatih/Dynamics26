## Authoritative preflight kuralı

`AnalysisService::preflight()` tek validation source of truth'tur. UI bu raporu kopyalayan veya farklı kurallar üreten ikinci bir validator taşımaz.

`PreflightCheck` engineering bilgisini şu alanlarla taşır:

```text
Status
Label
Detail
Subject ObjectId
```

UI bu veriyi üç amaçla kullanır:

1. problemi görünür kılmak,
2. ilgili engineering object'e güvenli navigation sağlamak,
3. yalnız açık ve güvenli olduğu durumda mevcut canonical command ile quick-fix sunmak.

## Tamamlanan Alpha.4 davranışları

### 1. Actionable diagnostic navigation

Failed / Warning kontrolünde geçerli `subject ObjectId` varsa kullanıcı canonical object-selection yolu ile ilgili engineering object'e yönlendirilir.

- Navigator + Details aynı object bağlamına gider,
- navigation engineering mutation değildir,
- document Undo index'i değişmez.

**Durum:** `TEST PASSED ✅` / `FEATURE WORKS ✅`

### 2. Mesh quick-fix

Preflight subject gerçek `ObjectType::Mesh` ise mevcut `mesh.generate` command yolu kullanılır.

- diagnostic label metnine göre routing yapılmaz,
- generated FEM mesh current model state'ten üretilir,
- derived mesh generation document Undo transaction değildir.

**Durum:** `TEST PASSED ✅` / `FEATURE WORKS ✅`

### 3. Missing Fixed Support / Force authoring

Analizde aktif mesnet veya yük yoksa mevcut canonical insertion command'leri kullanılır.

- `analysis.insertSupport`
- `analysis.insertForce`

Her insertion tam bir document Undo transaction üretir ve Undo ile başlangıç model durumu geri gelir.

**Durum:** `TEST PASSED ✅` / `FEATURE WORKS ✅`

### 4. Boundary Condition → referenced Named Selection navigation

Fixed Support / Force `Named Selection` scoping method kullanıyorsa referenced persistent Named Selection'a navigation desteklenir.

- mevcut ObjectId kullanılır,
- dangling ObjectId güvenli şekilde engellenir,
- navigation document mutation değildir,
- stale fakat mevcut Named Selection için Edit Selection repair workflow'u kullanılabilir.

**Durum:** `TEST PASSED ✅` / `FEATURE WORKS ✅`

### 5. Preflight summary + first issue navigation
