# FEMCAE V0.8.0 — Nonlinear Solver Architecture

**Tarih:** 29 Ağustos 2026  
**Durum:** Source-level scope complete; native macOS GUI/backend execution gate açık.

## 1. Amaç

V0.8, V0.7'nin finite-strain residual/tangent evaluator'ını gerçek bir nonlinear static solution algorithm ile sürer. Element matematiği, assembly ve iteration controller birbirine gömülmez.

```text
model_t
  ↓
evaluate_nonlinear_system(u, λ)
  ↓
nonlinear_system_t {K_T, R, f_int, f_ext, min J, energy}
  ↓
solve_nonlinear_static()
  ↓
LinearSolver abstraction
  ↓
trial / commit / revert
```

Bu ayrım V0.9 constitutive modellerinin Newton controller'ı değiştirmeden eklenebilmesi için zorunludur.

## 2. Residual ve tangent sözleşmesi

```text
R(u, λ) = λ f_ext - f_int(u)
K_T Δu = R
u_new = u + α Δu
```

V0.7 ile aynı residual sign convention korunur. `K_T`, internal-force Jacobian'ıdır; residual'ın türevi `-K_T` olduğundan Newton correction yukarıdaki biçimdedir.

## 3. Solver katmanları

### 3.1 Step controller

- load factor `λ ∈ [0,1]`,
- initial/min/max increment,
- accepted-step sayacı,
- attempt sayacı,
- adaptive growth,
- cutback,
- last-converged checkpoint.

### 3.2 Iteration controller

- Full Newton: tangent her correction öncesi yeniden kurulur.
- Modified Newton: step'in ilk tangent'i step boyunca kullanılır.
- Linear solution `LinearSolver` facade üzerinden yapılır.

### 3.3 Backtracking line search

Tam correction önce `α=1` ile denenir. Residual normu azalmazsa `α` reduction factor ile küçültülür. Hiçbir admissible trial state residual'ı azaltmazsa step başarısız sayılır ve outer controller rollback/cutback uygular.

## 4. Convergence

Her history entry aşağıdakileri saklar:

- attempt,
- accepted step count before attempt,
- Newton iteration,
- load factor ve increment,
- residual norm / relative residual,
- displacement correction norm / relative correction,
- energy measure / relative energy,
- line-search alpha,
- minimum `J`,
- converged flag.

Kriterler options ile ayrı ayrı etkinleştirilir. En az bir kriter zorunludur.

## 5. State lifecycle

```text
last committed state
      ↓ begin_trial
trial state
      ↓ Newton / line search
   ┌──┴─────────────┐
 converge          fail
   ↓                 ↓
 commit            revert
   ↓                 ↓
 next step         cutback + retry
```

Failure sonrasında committed state overwrite edilmez. Bu sözleşme V0.9 material-point internal-variable state için de aynen kullanılacaktır.

## 6. Checkpoint / restart

`nonlinear_checkpoint_t`:

- `load_factor`,
- `accepted_steps`,
- `active_displacement`.

`solve_nonlinear_static(..., initial_checkpoint=...)` checkpoint'ten continuation yapabilir. V0.8'de checkpoint RAM içi veri nesnesidir; project/restart dosyası serialization'ı henüz yoktur.

## 7. Model sınırları

V0.8 baseline:

- load-controlled nonlinear static,
- zero-valued essential BC,
- V0.7 `TOTAL_LAGRANGIAN_HEX8`,
- StVK verification material.

Bilinçli exclusions:

- nonzero prescribed-displacement stepping,
- arc-length / Riks,
- follower surface-pressure integration,
- contact,
- hyperelasticity/plasticity,
- mixed `u-p`,
- durable restart file.

## 8. C API ve GUI

```text
Qt Widgets / optional VTK
        ↓
fem_demo_nonlinear_hex8
        ↓
Fortran model + nonlinear solver
```

C API summary + convergence history döndürür. Qt, Newton matematiğini C++ içinde yeniden uygulamaz.

GUI paneli method, increment limits, iteration limit, line search ve adaptive stepping seçeneklerini taşır. Convergence table C API history'sinden doldurulur.
