# FEMCAE V0.3.0 — Element Kernel Architecture

## 1. Amaç

V0.3.0, element-local matematik çekirdeğini global assembly ve solver'dan bağımsız kurar. Ana hedef, her formulation'ın tekrar kullanabileceği güvenilir bir reference-element / quadrature / mapping / kinematics tabanı oluşturmaktır.

## 2. Katmanlar

```text
fem_reference_elements
        ↓
fem_shape_functions     fem_quadrature
        ↓                    ↓
        └──────→ fem_jacobian
                     ↓
              fem_element_kernel
                     ↓
             fem_element_results
                     ↓
           fem_element_kinematics
```

`fem_element_registry` bu matematik zincirinden bağımsız olarak topology ile formulation kimliğini ayırır.

## 3. Reference element sözleşmesi

### BAR2

```text
node 1: xi = -1
node 2: xi = +1
```

### QUAD4

```text
1 (-1,-1)
2 (+1,-1)
3 (+1,+1)
4 (-1,+1)
```

### HEX8

Alt yüz önce, üst yüz sonra; her yüz QUAD4 ile aynı counter-clockwise doğal sıra mantığını korur.

Bu sıra connectivity ile shape function sıra sözleşmesidir ve regression/partition testleriyle kilitlenmiştir.

## 4. Shape gradient matris düzeni

```text
dshape_dnatural(j,a) = dN_a / dxi_j
```

Square mapping için:

```text
J(i,j) = dx_i / dxi_j
```

Physical gradient:

```text
dN_a/dx_i = sum_j (dN_a/dxi_j) * (dxi_j/dx_i)
```

Kod karşılığı `transpose(invJ) * dN_dxi` matris çarpımıdır.

## 5. Embedded BAR2 / TRUSS2

TRUSS2 3B uzayda 1B reference coordinate kullanır. Bu nedenle 3x1 Jacobian'ın klasik matris inverse'i yoktur. Ayrı line metric tanımı kullanılır:

```text
t = dx/dxi
J_line = ||t||
e = t / ||t||
dN/ds = (dN/dxi) / J_line
```

Node sırasının ters çevrilmesi direction vektörünü değiştirir; line measure pozitif kalır. Bu, truss için fiziksel olarak beklenen davranıştır.

## 6. Gauss quadrature

V0.3.0:

- 1 nokta/eksen,
- 2 nokta/eksen,
- 1B/2B/3B tensor-product üretimi

destekler.

Standart full integration:

```text
BAR2  -> 2 point
QUAD4 -> 2x2
HEX8  -> 2x2x2
```

Reduced/selective integration ileriki formulation sürümlerine bırakılmıştır.

## 7. Jacobian singularity ve orientation

Boyutlu mutlak `detJ` toleransı kullanılmaz. Square Jacobian için:

```text
scaled_det = |detJ| / max(|J_ij|)^dimension
```

ve dimensionless singular tolerance uygulanır.

Sonra orientation ayrı kontrol edilir:

```text
detJ > 0  -> kabul
detJ < 0  -> inverted/orientation error
```

Bu ayrım birim ölçeğine duyarsızdır.

## 8. Axisymmetric prototype

Axisymmetric QUAD4, yeni bir topology değildir. QUAD4 shape/Jacobian zincirini kullanır ve integration measure'a:

```text
2*pi*r
```

çarpanı ekler.

Small-strain axisymmetric sıra:

```text
[eps_rr, eps_zz, gamma_rz, eps_tt]
```

ve:

```text
eps_tt = u_r / r
```

kullanılır.

V0.3 yalnız geometry/kinematics prototype sağlar; constitutive/stiffness V0.5 lineer formulation aşamasına aittir.

## 9. Element registry

Topology ile formulation ayrıdır:

```text
BAR2  -> TRUSS2
      -> BEAM2_PROTOTYPE

QUAD4 -> PLANE_STRESS_QUAD4
      -> PLANE_STRAIN_QUAD4
      -> AXISYM_QUAD4
      -> SHELL_QUAD4_PROTOTYPE

HEX8  -> SOLID_HEX8
```

Beam/shell prototype metadata'sı rotation component ve section gereksinimini şimdiden taşır. Çözüm kernel'i henüz uygulanmamıştır.

## 10. Patch test mantığı

Affine displacement alanı:

```text
u(x) = c + A*x
```

lineer strain üretir. Nodal displacement'lar bu alandan örneklenip element B-matrix üzerinden strain hesaplandığında aynı sabit strain'in yeniden üretilmesi gerekir.

V0.3 patch seti:

- TRUSS2,
- distorted QUAD4,
- axisymmetric QUAD4,
- affine HEX8.

Bu testler global assembly içermeden element kinematiğinin gerçek FEM anlamında ilk doğrulamasıdır.

## 11. V0.4'e verilen sözleşme

V0.4 assembly katmanı şunları hazır kabul edebilir:

- deterministic DOF/equation map,
- topology/formulation ayrımı,
- full-integration quadrature noktaları,
- physical shape gradients,
- positive-Jacobian enforcement,
- element-local integration measure,
- plane/solid/axisymmetric B-matrix temeli.

V0.4 bu altyapının üstüne local stiffness/residual üretimi ve global sparse scatter ekleyecektir.
