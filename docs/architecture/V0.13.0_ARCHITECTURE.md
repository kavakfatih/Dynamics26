# FEMCAE V0.13.0 — Meshing + Full Pre/Post Architecture

## 1. Amaç

V0.13.0, V0.12 CAD/Geometry katmanı ile Fortran çözüm çekirdeği arasındaki eksik köprüyü kurar. Ana mimari sözleşme değişmez:

```text
CAD Geometry != Display Tessellation != FEM Mesh
```

CAD B-Rep model seçim/provenance kaynağıdır. Display tessellation yalnız görselleştirme içindir. `SimulationMesh` ise solver'a giden bağımsız FEM discretization katmanıdır.

## 2. Katmanlar

```text
OCCT / GeometryDocument
        |
        | GeometryEntityId + source revision
        v
MeshingPlan / StructuredHexMesher / ExternalMeshReader
        |
        | SimulationMesh
        | nodes / HEX8 / boundary facets / provenance
        v
AssignmentResolver
        |
        | geometry -> FEM node/facet/element IDs
        v
Public C ABI
        |
        v
Modern Fortran FEM Core
DOF -> Sparse Assembly -> Linear Solve -> Stress Recovery
        |
        v
ResultDatabase
probe / plane-cut selection / CSV / legacy VTK
        |
        v
Qt + VTK Pre/Post Panel
```

## 3. `femcae_meshing` kütüphanesi

Yeni C++20 static library `femcae_meshing`, `femcae_geometry` üzerine kurulur fakat Fortran module ABI'sine doğrudan bağlanmaz.

### Temel veri yapıları

- `SimulationMesh`
- `MeshNode`
- `MeshElement`
- `MeshFacet`
- `MeshQuality`
- `MeshingPlan`
- `AssignmentStore`
- `ResolvedAssignment`
- `ResultDatabase`

Mesh entity ID'leri CAD geometry ID'lerinden ayrıdır. Her mesh entity yalnız provenance amacıyla `sourceGeometryId` taşıyabilir.

## 4. Structured HEX8 baseline

V0.13 production claim'i genel amaçlı otomatik CAD volume mesher değildir. Doğrulanmış baseline, eksenlere hizalı bir kutuyu `nx × ny × nz` adet HEX8'e bölen deterministic structured mesher'dır.

Boundary QUAD4 facet'leri altı CAD face ID'sine ayrı ayrı bağlanabilir. Bu sayede örneğin `xMin` geometry face constraint'i doğrudan ilgili FEM boundary node'larına çözülebilir.

### Local sizing baseline

`MeshingPlan` global target size ve geometry-face local target size içerir. Structured box baseline'ında local size, ilgili yüzün tangent yönlerindeki bölme sayısını artırır. Bu özellik spatially graded unstructured adaptive refinement olarak yorumlanmaz.

## 5. External mesh sınırı

Portable Abaqus ASCII reader şu minimum sözleşmeyi destekler:

- `*NODE`
- `*ELEMENT, TYPE=C3D8`

Material, section, boundary condition, load, contact veya Abaqus analysis keyword'leri V0.13 reader kapsamı değildir.

## 6. Mesh quality

V0.13 baseline kalite raporu:

- center scaled Jacobian,
- maximum aspect ratio,
- inverted element count,
- degenerate element count

üretir. Bu, production mesh certification için bütün olası metriklerin tamamı değildir; all-Gauss Jacobian, face warpage, skewness ve angle metrics V1.0 hardening adaylarıdır.

## 7. Geometry assignment çözümleme

Material/section/load/constraint/contact metadata CAD geometry ID üzerinde tutulabilir. Face assignment'ı node üzerindeki tek bir `sourceGeometryId` tahminine dayanmaz; boundary facet provenance üzerinden çözülür. Böylece corner/edge node'ları doğru face assignment setine dahil olur.

## 8. CAD → FEM provenance

`GeometryMeshBridge`, V0.12 `GeometryAssociationMap` ile mesh entity'lerini ilişkilendirir:

```text
CAD Body -> FEM Elements
CAD Face -> FEM Boundary Facets + Nodes
```

`sourceGeometryRevision` mesh'in hangi CAD revision'dan türetildiğini gösterir. CAD revision değiştiğinde eski mesh'in stale olduğu anlaşılabilir.

## 9. Generic linear HEX8 C ABI

V0.13, preset olmayan ilk arbitrary linear HEX8 mesh solve C API'sini ekler:

```c
fem_solve_linear_hex8_mesh(...)
```

Girdi:

- node ID + xyz,
- HEX8 element ID + connectivity,
- `E`, `nu`,
- nodal displacement constraints,
- nodal loads.

Çıktı:

- nodal displacement,
- nodal reaction,
- element von Mises.

Bu ABI V0.13'te yalnız linear HEX8 workflow içindir. Generic nonlinear/mixed/contact arbitrary-mesh ABI olarak yorumlanmaz.

## 10. Post-processing

`ResultDatabase` şunları sağlar:

- nodal displacement vector field,
- element scalar field,
- nearest-node probe,
- plane ile kesişen element ID selection,
- CSV export,
- legacy ASCII VTK export.

Plane cut gerçek cut-surface interpolation/contour üretmez; kesişen elementleri seçen baseline'dır.

## 11. GUI

Yeni `Mesh / Pre-Post` paneli:

- structured HEX8 mesh,
- mesh quality,
- geometry-face BC/load resolution,
- linear HEX8 solve,
- deformed shape + von Mises contour,
- probe,
- section-cut element selection,
- CSV/VTK export

akışını sunar.

V0.6'dan gelen modal animation altyapısı korunur. V0.13 static post-processing tarafında deformed contour baseline sunar.

## 12. Native OCCT köprüsü

OCCT etkin build'de axis-aligned STEP box body için bounds ve altı CAD face ID'si çıkarılabilir. Native `VER-V130-002`, STEP box -> GeometryDocument -> structured HEX8 -> boundary provenance zincirini doğrular.

Bu test Linux portable hostta PASS sayılmaz; `macos-15` + OCCT release gate'idir.

## 13. V0.13 kapsam dışı

- arbitrary curved STEP body için production tetra/hex meshing,
- boundary-layer meshing,
- adaptive error-estimator refinement,
- mesh morphing,
- arbitrary nonlinear/mixed/contact generic C ABI,
- interpolated cut-surface result contours,
- full Abaqus INP model import,
- distributed/parallel meshing.
