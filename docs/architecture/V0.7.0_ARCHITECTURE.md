# FEMCAE V0.7.0 Architecture — Finite Strain / Geometric Nonlinearity

## 1. Amaç

V0.7, V0.8 Newton solver'ının ihtiyaç duyacağı nonlinear continuum matematiğini solver algoritmasından bağımsız kurar.

Ana mimari ilke:

```text
Nonlinear solution algorithm != nonlinear system evaluation
```

V0.7 yalnız `u_trial` verildiğinde `R(u)` ve `K_T(u)` üretir. İterasyon, line search ve increment yönetimi V0.8'e aittir.

## 2. Katmanlar

```text
Model / Mesh / DOF / Constraints
        ↓
Reference coordinates X
        ↓
Trial displacement u
        ↓
Finite-strain kinematics
F, J, C, E
        ↓
Reference constitutive response
StVK: E → S, C_material
        ↓
TOTAL_LAGRANGIAN_HEX8
f_int, K_mat, K_geo
        ↓
Sparse nonlinear assembly
f_ext, f_int, R, K_T
        ↓
V0.8 nonlinear solver
```

## 3. Yeni modüller

### `fem_finite_strain_kinematics`

- `configuration_pair_t`
- `F`
- `J`
- right/left Cauchy-Green
- Green-Lagrange
- Euler-Almansi
- PK2 → PK1/Kirchhoff/Cauchy

### `fem_stvk_material`

Reference constitutive verification modeli. Existing isotropic elastic material parametrelerini (`E`, `ν`) kullanır; yeni bir kauçuk material registry iddiası taşımaz.

### `fem_total_lagrangian_hex8`

24 DOF HEX8 için:

- IP finite-strain state,
- nonlinear B matrix,
- internal force,
- material tangent,
- geometric tangent,
- Cauchy recovery,
- strain energy.

### `fem_nonlinear_assembly`

Trial active-displacement vectoründen sparse global sistem üretir. Newton iteration yapmaz.

### `fem_nonlinear_state`

Global displacement trial/commit/revert baseline.

### `fem_nonlinear_loads`

Follower-load configuration/tangent metadata sözleşmesi.

## 4. Formulation ayrımı

Linear HEX8 ve finite-strain HEX8 aynı topolojiyi paylaşır ancak formulation ID'leri ayrıdır:

```text
TOPOLOGY_HEX8
   ├── SOLID_HEX8                 (small strain linear)
   └── TOTAL_LAGRANGIAN_HEX8      (finite strain geometric nonlinear)
```

Bu ayrım topology'nin physics/formulation ile karıştırılmasını önler.

## 5. Tangent sözleşmesi

Element seviyesinde:

```text
K_internal = K_material + K_geometric
```

Global residual:

```text
R = f_ext - f_int
```

Follower loads eklendiğinde Newton effective tangent:

```text
K_Newton = ∂f_int/∂u - ∂f_ext/∂u
```

olacaktır. V0.7'de gerçek follower load yoktur; external tangent sıfırdır ve assembled tangent internal tangent'e eşittir.

## 6. State yaşam döngüsü

V0.7'de nonlinear displacement state:

```text
committed → begin_trial → trial updates
                     ├── commit
                     └── revert
```

Material/contact history state için V0.1 `state_buffer_t` sözleşmesi korunur. V0.8 iki seviyeyi load-step/iteration yaşam döngüsünde birleştirecektir.

## 7. Objectivity gate

İki ayrı release gate vardır:

- pure rigid rotation,
- finite deformation + superposed rigid rotation.

İkincisi yalnız `E=0` testinden daha güçlüdür; deforme durumdaki Cauchy stress'in doğru spatial rotation'ını da doğrular.
