# FEMCAE V0.9.0 — Constitutive Architecture

## 1. Amaç

V0.9, V0.8 nonlinear solution controller ile element formulation'ları arasına açık bir constitutive material-point sınırı yerleştirir. Ana amaç rubber hyperelasticity'yi gerçek Total-Lagrangian/Newton yoluna bağlamak ve stateful plasticity için aynı mimariyi bozmadan genişleyebilecek temel oluşturmaktır.

## 2. Bağımlılık yönü

```text
model
 ├─ hyperelastic material registry
 ├─ linear material registry (legacy/StVK verification)
 └─ element properties
        ↓
nonlinear assembly
        ↓
TL HEX8 element
        ↓
constitutive interface
        ├─ hyperelastic response
        └─ J2 material-point response
```

Element, constitutive modelin katsayı denklemlerini bilmez. Constitutive response ise hangi stress ve tangent measure'ı döndürdüğünü açık metadata ile bildirir.

## 3. Constitutive response contract

`constitutive_response_t`:

```text
stress_measure
tangent_measure
stress(3,3)
tangent(6,6)
strain_energy_density
equivalent_stress
internal_variable
stateful
tangent_is_consistent
```

V0.9 hyperelastic path:

```text
stress_measure  = SECOND_PK
tangent_measure = dS/dE
stateful         = false
```

J2 baseline:

```text
stress_measure  = CAUCHY
tangent_measure = dσ/dε
tateful          = true
```

Bu ayrım önemlidir: farklı stress/tangent measure'ları sessizce aynı element denklemine takılamaz.

## 4. Hyperelastic registry

`model_t` içinde hyperelastic malzemeler ayrı registry'de tutulur. Elementin `material_id` değeri nonlinear assembly sırasında hyperelastic registry'de aranır. Bulunursa TL-HEX8 hyperelastic overload çağrılır. Bulunmazsa V0.7/V0.8 StVK verification path geriye dönük olarak korunur.

Bu geçiş additive'tir; önceki verification testleri kırılmaz.

## 5. Hyperelastic model ailesi

Ortak veri tipi:

```text
hyperelastic_material_t
  id
  name
  model
  density
  bulk_modulus K
  C10, C01, C20, C30
  Ogden: 1..3 × (mu_i, alpha_i)
```

Ortak response:

```text
F → W(F), S, dS/dE
```

Neo-Hookean, Mooney-Rivlin ve Yeoh invariant temelli analitik directional derivative kullanır. Ogden principal-stretch/spectral response kullanır; repeated/near-repeated eigenvalue limiti ayrı dal ile ele alınır.

Production constitutive tangent finite-difference değildir. Finite difference yalnız bağımsız verification referansıdır.

## 6. Ogden parametre politikası

V0.9 baseline 1–3 terim destekler. Çok-terimli fitting için tekil `mu_i` katsayıları işaretli olabilir; validasyon:

- aktif `mu_i != 0`,
- aktif `alpha_i != 0`,
- `sum(mu_i) > 0`

koşullarını uygular.

Bu, başlangıç shear modulus'unun pozitif kalmasını sağlar fakat tüm deformation uzayında global convexity/stability garantisi değildir. Malzeme fitting kalite/stability analizi ayrı bir mühendislik problemidir.

## 7. J2 state mimarisi

`j2_state_t` committed/trial alanlarını ayrı saklar:

```text
committed_plastic_strain
trial_plastic_strain
committed_equivalent_plastic_strain
trial_equivalent_plastic_strain
```

ve:

```text
initialize
begin_trial
commit
revert
```

yaşam döngüsüne sahiptir. Bu, V0.8 nonlinear rollback contract ile uyumludur.

V0.9 J2 global element entegrasyonu yapmaz; bu aşama material-point ve state/tangent foundation'dır.

## 8. C ABI / GUI sınırı

Material Studio constitutive denklemleri C++ tarafında yeniden uygulamaz:

```text
Qt Material Studio
        ↓
fem_hyperelastic_validate
fem_hyperelastic_isochoric_uniaxial_preview
        ↓
Fortran hyperelastic engine
```

Böylece önizleme ile solver'da kullanılan model aynı constitutive kaynak kodundan gelir.

## 9. V0.10 için hazırlanan sınır

V0.9 penalty volumetric energy kullanır. V0.10'da displacement-pressure mixed formulation geldiğinde:

- constitutive deviatoric/isochoric response,
- pressure field,
- volumetric constraint residual,
- block tangent

ayrılacaktır. Element içinde malzeme `select case` çoğaltılmadığı için bu geçiş kontrollü yapılabilir.

## 10. Bilinçli kapsam dışı

- mixed `u-p`,
- locking-free incompressibility,
- contact/friction,
- finite-strain multiplicative plasticity,
- global J2 plastic element solution,
- material parameter fitting optimizer,
- arbitrary GUI mesh/model editor.
