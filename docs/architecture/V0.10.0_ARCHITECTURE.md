# FEMCAE V0.10.0 — Mixed u-p / Incompressibility Architecture

## 1. Amaç

V0.10, V0.9 hyperelastic constitutive çekirdeğini nearly-incompressible elastomerler için displacement-pressure mixed formulation'a bağlar. Contact bu sürümde özellikle yoktur; amaç incompressibility ve saddle-point sistem mimarisini tek başına doğrulamaktır.

## 2. Field ve DOF mimarisi

V0.2'de kurulan `entity ID != DOF ID != equation ID` sözleşmesi korunur.

Yeni baseline pressure field:

- field: `FIELD_ID_PRESSURE_P0`
- association: **element**
- component count: 1
- interpolation: **P0 / element başına sabit pressure**

`MIXED_UP_HEX8_P0` local ordering:

```text
[u1x,u1y,u1z,...,u8x,u8y,u8z,p_element]
```

Toplam 25 local unknown vardır. Pressure bir node ID'sine değil element ID'sine bağlanır.

## 3. Neden Q1/P0?

V0.10 başlangıcında displacement için standard trilinear HEX8/Q1, pressure için element-constant P0 seçilmiştir. Equal-order Q1/Q1 pressure alanı stabilizasyon olmadan eklenmemiştir.

Bu seçim şu iddiayı **yapmaz**:

- arbitrary meshlerde evrensel inf-sup stability,
- checkerboard-free tüm mesh/topology davranışı,
- production-grade hybrid element ailesinin tamamlanması.

V0.10 controlled baseline'dır. Stabilized Q1/Q1, higher-order mixed pairs ve mesh-family convergence sonraki hardening işidir.

## 4. Constitutive sınır

Hyperelastic denklemler mixed element içine kopyalanmaz. V0.9 constitutive boundary korunur:

```text
F
 ↓
hyperelastic_isochoric_response
 ↓
W_iso + S_iso + dS_iso/dE
```

Mixed element yalnız pressure constraint ve pressure stress/tangent katkısını ekler.

## 5. Mixed potential ve blok sistem

Baseline perturbed-Lagrangian potential:

```text
Psi(u,p) = W_iso(Fbar) + p (J - 1) - p^2/(2K)
```

Pressure sign convention: **pozitif tension**.

Pressure stationarity:

```text
R_p = integral[(J - 1) - p/K] dV0 = 0
```

ve homogeneous durumda:

```text
p = K (J - 1)
```

Coupled tangent:

```text
[ K_uu  K_up ]
[ K_pu  K_pp ]
```

Aynı scalar potential'dan türetildiği için consistent local tangent simetriktir ve `K_up = K_pu^T` verification ile kontrol edilir.

## 6. Global assembly

`fem_nonlinear_assembly` hem displacement-only TL-HEX8 hem mixed HEX8/P0 elementlerini aynı global sparse equation space'te assemble eder.

Mixed system metadata:

- displacement unknown count,
- pressure unknown count,
- `has_mixed_pressure`,
- displacement residual norm,
- pressure residual norm.

Aktif fakat hiçbir formulation tarafından kullanılmayan DOF, singular solve'a bırakılmadan explicit error olur.

## 7. Nonlinear solver

Displacement residual ve pressure residual farklı fiziksel boyutlara sahip olduğu için mixed çözümde tek Euclidean residual norm convergence ölçütü olarak kullanılmaz.

Solver ayrı takip eder:

- displacement residual norm,
- pressure residual norm,
- displacement correction norm,
- pressure increment norm.

Line-search mixed merit'i incremental work tabanlıdır:

```text
|Delta_q^T R|
```

Bu toplamda displacement×force ve pressure×volume terimleri enerji boyutuna gelir.

## 8. Linear solver şartı

Mixed tangent saddle-point ve genel olarak indefinite'dır. Bu nedenle mevcut Jacobi-CG backend mixed formulation için explicit olarak reddedilir.

V0.10 baseline:

- Dense reference direct solver: verification/reference
- Apple Accelerate sparse direct: macOS direct backend sınırı
- CG: mixed sistemde yasak

Daha büyük production modelleri için symmetric-indefinite sparse factorization hardening veya PETSc/MUMPS benzeri opsiyonel backend ileride değerlendirilecektir.

## 9. Pressure result data path

`fem_mixed_results` P0 pressure'ı element-associated DOF'dan recover eder ve:

```text
element_id -> pressure
```

olarak saklar. V0.10 P0 pressure'ı nodal pressure gibi extrapolate etmez.

## 10. C API / GUI

C ABI'ye `fem_demo_mixed_up_hex8_shear` verification preset'i eklenmiştir. Qt analiz panelinde:

- displacement-only / penalty,
- mixed u-p HEX8/P0 verification

seçimi görünürdür. Mixed GUI akışı manufactured simple-shear doğrulama preset'idir; arbitrary mixed mesh preprocessor değildir.
