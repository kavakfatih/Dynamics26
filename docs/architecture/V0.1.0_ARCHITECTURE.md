# V0.1.0 Architecture Summary

V0.1.0 henuz mesh/element/assembly solveri degildir. Bu surumun gorevi V0.2-V1.0 arasinda kirilmasi en pahali kontratlari kod ve test seviyesinde sabitlemektir.

## Dependency direction

```text
future Qt/C++
    ↓
stable C API
    ↓
solver layers (future)
    ↓
math + foundation (V0.1.0)
```

## Bu surumde bilincli olarak bulunmayanlar

- node/mesh model
- real finite element kernel
- global sparse assembly
- Apple Accelerate backend implementation
- Qt GUI
- VTK
- CAD
- hyperelasticity/contact

Bunlar roadmap'teki sonraki surumlerde eklenecektir; V0.1.0 yalnizca bu sistemlerin dayanacagi temel kontratlari tanimlar.
