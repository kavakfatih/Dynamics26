# FEMCAE V0.11.0 — Contact / Friction Architecture

## 1. Mimari hedef

V0.11'in temel kuralı contact'ı material/element formulation içine gömmemektir. Contact; model registry, geometry/search, enforcement/state ve global assembly katmanlarından oluşan ayrı bir subsystem'dir.

```text
model_t
 ├─ mesh / fields / dofs
 ├─ materials / sections / loads
 ├─ elements
 └─ contacts
      ├─ pairs
      │   ├─ slave node IDs
      │   ├─ rigid master facets
      │   ├─ parameters
      │   └─ point states
      └─ trial / commit / revert
```

Bu ayrım sayesinde V0.10 mixed `u-p` element veya V0.9 hyperelastic constitutive code contact algoritmasıyla kopyalanmaz.

## 2. Baseline topology

Master taraf:

- planar QUAD4 facet,
- rigid kabul edilir,
- facet dört mevcut mesh node ID'si ile tanımlanır,
- node sırası master normal yönünü belirler.

Slave taraf:

- deformable nodal displacement DOF'ları,
- her slave node için ayrı contact-point state.

Bu baseline node-to-rigid-surface contact'tır; deformable-deformable veya mortar değildir.

## 3. Search katmanı

### Broad phase

Master facet için axis-aligned bounding box hesaplanır ve `search_distance` kadar genişletilir. Uzak facet'ler narrow-phase'e taşınmaz.

### Narrow phase

Planar QUAD4 iki triangle'a bölünür ve closest point adayları arasından minimum distance seçilir.

Search result:

- master facet ID,
- closest point,
- unit normal,
- signed gap,
- Euclidean distance,
- candidate count

taşır.

V0.11 search O(slave×facet) baseline'dır. BVH hierarchy henüz yoktur.

## 4. Enforcement katmanı

Contact evaluator global equation ID bilmez. Yalnız geometric search result + contact state + pair parameterlerinden local force/tangent üretir.

Normal seçenekler:

- penalty,
- augmented Lagrangian.

Friction seçenekler:

- frictionless,
- Coulomb.

Response:

- active flag,
- OPEN/STICK/SLIP state,
- gap,
- normal force,
- tangential force norm,
- 3B contact force,
- 3×3 effective tangent.

## 5. State ownership

Her slave point:

- committed/trial master facet ID,
- OPEN/STICK/SLIP status,
- normal multiplier,
- gap,
- tangential traction,
- position

saklar.

`begin_trial()` committed veriyi trial'a kopyalar. `commit()` yalnız converged load step sonunda çağrılır. `revert()` failed/cutback step'te trial'ı committed state'e döndürür.

Bu yapı rejected line-search candidate'ın contact history'yi kalıcı olarak değiştirmesini önler.

## 6. Global assembly

`fem_contact_assembly`:

1. slave node displacement DOF/equation map'ini bulur,
2. current slave position'ı reconstruct eder,
3. broad/narrow search yapar,
4. enforcement response üretir,
5. contact force'u nonlinear residual'e ekler,
6. 3×3 contact tangent'i CSR global tangent'e scatter eder.

Global system ayrıca active/stick/slip count, maximum penetration ve normal/tangential resultants taşır.

## 7. Solver contracts

Residual sign convention korunur:

```text
R = f_ext - f_int + f_contact
K_T Δu = R
```

Contact effective tangent:

```text
K_contact = - ∂f_contact / ∂u_slave
```

Friction tangent unsymmetric/general olabilir. Bu nedenle contact model varlığında V0.11 CG backend'i açıkça reddeder ve direct/reference solver bekler.

Contact-state serialization checkpoint formatında henüz olmadığı için contact + restart da açıkça reddedilir.

## 8. GUI / ABI sınırı

Qt doğrudan Fortran contact type'larına bağlanmaz:

```text
Qt / C++
   ↓
public C ABI
   ↓
Fortran nonlinear/contact subsystem
```

`fem_demo_contact_hex8` ilk GUI/consumer verification sınırıdır.

## 9. Geleceğe açık noktalar

Mevcut registry/search/enforcement ayrımı aşağıdaki genişlemeler için tasarlanmıştır fakat V0.11'de uygulanmış değildir:

- deformable master surface,
- facet/segment contact DOF coupling,
- mortar,
- self-contact,
- BVH/kd-tree search backend,
- higher-order/curved surface,
- contact pressure contour result mapping.
