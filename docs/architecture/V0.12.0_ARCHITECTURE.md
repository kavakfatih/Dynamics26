# FEMCAE V0.12.0 — CAD / Geometry / Sections Architecture

## 1. Temel mimari kural

V0.12'nin en önemli sözleşmesi:

```text
CAD Geometry != Display Tessellation != FEM Mesh
```

Bu üç veri kümesi farklı sahiplik, kimlik ve yaşam döngüsüne sahiptir.

- **CAD Geometry**: B-Rep/topoloji, body/face/edge/vertex, isim ve kaynak bilgisi.
- **Display Tessellation**: yalnız viewport çizimi için üçgenler; solver node/element ID taşımaz.
- **FEM Mesh**: V0.13 CAD-to-mesher katmanının üreteceği analiz ağıdır.

Display tessellation'ın yanlışlıkla solver mesh'i olarak kullanılması mimari ihlaldir.

## 2. Portable geometry domain

Yeni `femcae_geometry` C++20 static library, solver Fortran core'dan bağımsızdır.

Public başlıklar:

- `GeometryTypes.h`
- `GeometryDocument.h`
- `SectionProfile.h`
- `DxfSectionReader.h`
- `OcctStepImporter.h`

Geometry entity türleri:

- Assembly
- Body
- Face
- Edge
- Vertex
- Surface
- Curve

`GeometryEntityId` 64-bit unsigned ID'dir; `0` invalid kabul edilir. ID, document namespace + persistent key üzerinden FNV-1a hash ile deterministik üretilir.

### Persistent naming sınırı

Bu ID sistemi aynı, değişmemiş STEP topolojisinin tekrar importunda deterministik anahtar sağlar. CAD modelinde split/merge/reorder gibi topolojik değişiklikler sonrası semantik face eşleştirmesi yapan tam bir topological naming algoritması değildir. V1.0 öncesi bu konu ayrıca harden edilecektir.

## 3. Geometry association / provenance

`GeometryAssociationMap`, CAD entity ile ileride türetilecek FEM entity'leri arasında provenance tutar:

```text
GeometryEntityId
  -> femNodeIds
  -> femElementIds
  -> femFacetIds
```

Bu map geometry document veya display tessellation'ın parçası değildir. Böylece mesh regenerate edildiğinde CAD kimliği ve FEM kimliği birbirine eşitlenmez.

## 4. OCCT / STEP adapter

`OcctStepImporter` public API'si her build'de bulunur.

- OCCT bulunduğunda `FEMCAE_GEOMETRY_HAS_OCCT=1` ile gerçek XDE/STEPCAF adapter derlenir.
- OCCT bulunmadığında aynı API kontrollü stub davranışı verir.
- macOS native CI `FEMCAE_REQUIRE_OCCT=ON` kullanır; release CAD gate'inde stub ile sessiz PASS mümkün değildir.

STEP import yolu:

```text
STEPCAFControl_Reader
  -> XDE / OCAF document
  -> XCAFDoc_ShapeTool
  -> free roots
  -> solids / faces / edges / vertices
  -> FEMCAE GeometryDocument
```

V0.12 baseline assembly tree'yi root + body seviyesinde temsil eder; nested assembly instance graph'in tüm semantik ayrıntılarını production-ready olarak iddia etmez.

## 5. Display tessellation

OCCT `BRepMesh_IncrementalMesh` ile triangulation üretilir ve `GeometryTessellation` içine kopyalanır.

`GeometryTessellation`:

- source geometry ID,
- source revision,
- display points,
- triangle indices

taşır. FEM node/element listesi taşımaz.

Qt/VTK GUI bu yapıyı çizmek için kullanır.

## 6. DXF custom section

V0.12 portable ASCII DXF reader dış binary dependency gerektirmez. Baseline entity desteği:

- `LWPOLYLINE` (straight segments, closed flag),
- `LINE`,
- `CIRCLE`,
- `ARC`.

Nonzero LWPOLYLINE bulge bilinçli olarak reddedilir; arc geometri `ARC` entity üzerinden desteklenir. Açık contour da reddedilir.

Contour nesting, daha büyük enclosing loop sayısına göre outer/hole olarak sınıflandırılır.

## 7. Section properties

Kapalı contourlar Green teoremi tabanlı polygon integralleriyle işlenir.

Çıktılar:

- area `A`,
- centroid `Cx, Cy`,
- centroidal `Ixx`, `Iyy`, `Ixy`,
- principal moments `I1, I2`,
- principal-axis angle,
- polar area moment `Jp = Ixx + Iyy`.

`Jp`, genel açık/ince cidarlı kesitler için Saint-Venant torsion constant `J_t` değildir. V0.12 bu iki fiziksel büyüklüğü eşitlemez.

## 8. GUI

Yeni `GeometryPanel`:

- STEP/STP import,
- body/face/edge/vertex geometry tree,
- selection filter,
- DXF custom-section import,
- section property summary,
- project JSON içinde STEP/DXF source path persistence

sağlar.

OCCT tessellation varsa `ViewportWidget::showGeometryTessellation()` ile VTK'da görüntülenir. Bu işlem FEM mesh oluşturmaz.

## 9. V0.13 sınırı

V0.12'de bulunmayanlar:

- CAD-to-mesher production interface,
- automatic tetra/hex meshing,
- local mesh sizing/refinement,
- arbitrary CAD face -> load/BC assignment workflow,
- robust CAD edit sonrası semantic persistent naming,
- deformable CAD/mesh association regeneration,
- IGES production import,
- geometry healing UI,
- Saint-Venant torsion solver.

Bunların uygun kısmı V0.13 Meshing + Full Pre/Post, geri kalanı V1.0 hardening kapsamındadır.
