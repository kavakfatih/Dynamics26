# V1.0.0 Release Architecture

## Amaç

V1.0 mimari olarak yeni solver formulation eklemez. Amaç V0.x katmanlarını değiştirmeden doğrulama, hata izolasyonu, restart ve dağıtım sınırlarını güçlendirmektir.

## Katman sınırları

```text
Qt / VTK / OCCT UI & CAD adapters
              ↓ public C/C++ boundaries
Geometry / Meshing / Assignments / Results
              ↓ public C ABI
Modern Fortran FEM Core
              ↓
Element / Constitutive / Assembly / Solver / Nonlinear / Contact
```

Kritik sözleşmeler korunur:

- Node ID != array index != DOF ID != equation ID.
- CAD geometry != display tessellation != FEM mesh.
- Material-point constitutive response element implementationından ayrıdır.
- Trial / commit / revert history yalnız converged step'te commit edilir.
- Residual convention: `R = f_ext - f_int`.
- Newton convention: `K_T Δu = R`.

## Restart boundary

`nonlinear_checkpoint_t` için disk codec ayrı `fem_checkpoint_io` modülündedir. Solver dosya formatını bilmez. V1 schema displacement state + load factor + accepted-step sayısını taşır. Contact history taşımadığı için contact restart gate'i bilinçli olarak kapalıdır.

## Release boundary

Native macOS app:

```text
FEMCAE.app
 Contents/MacOS/FEMCAE
 Contents/Frameworks/*
 Contents/PlugIns/*
 Contents/Resources/*
```

Qt deployment Qt framework/plugin zincirini, CMake BundleUtilities ise non-system OCCT/VTK/ARPACK/gfortran runtime closure'ını tamamlamak üzere kullanılır.

Build-prefix veya Homebrew absolute dependency path'inin final Mach-O dosyalarında kalması release failure'dır.

## Güvenilmeyen input sınırları

DXF, Abaqus INP, project JSON ve checkpoint dosyaları güvenilmeyen input kabul edilir. Parserlar partial state bırakmadan explicit failure üretmelidir. V1 corrupted-input testleri bu sözleşmenin başlangıç gate'idir.
