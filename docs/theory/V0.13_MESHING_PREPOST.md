# V0.13 Meshing ve Pre/Post Teorik Notları

## 1. Discretization ayrımı

Geometrik B-Rep, görüntüleme tessellation'ı ve FEM mesh aynı veri değildir. FEM mesh fiziksel alanı sonlu elemanlara ayıran solver discretization'ıdır ve kendi node/element ID uzayına sahiptir.

## 2. Structured HEX8 mapping

Axis-aligned box

\[
[x_0,x_1]\times[y_0,y_1]\times[z_0,z_1]
\]

`nx`, `ny`, `nz` bölmeye ayrılır. Grid aralıkları:

\[
\Delta x=\frac{x_1-x_0}{n_x},\qquad
\Delta y=\frac{y_1-y_0}{n_y},\qquad
\Delta z=\frac{z_1-z_0}{n_z}
\]

olarak tanımlanır. HEX8 connectivity, V0.3 reference-element node ordering ile uyumludur.

## 3. Center scaled Jacobian

Bir element için center Jacobian `J_c` üzerinden baseline scaled Jacobian, determinantın characteristic column norm product'ına oranı olarak değerlendirilir. Pozitif değer orientation'ın doğru olduğunu, sıfıra yaklaşması degeneracy'yi, negatif değer inverted mapping'i gösterir.

V0.13 kalite metriği center-only'dir; production-quality certification için tüm integration point'ler ve ek shape metrikleri V1.0'da genişletilebilir.

## 4. Aspect ratio

Baseline aspect ratio, element edge-length karakteristiklerinin maksimum/minimum oranıdır. Structured orthogonal box'ta bu değer hücre boyutlarının oranına karşılık gelir.

## 5. CAD-face assignment provenance

Bir CAD yüzü `G_f` için boundary facet seti

\[
\mathcal{F}(G_f)=\{f\;|\;sourceGeometryId(f)=G_f\}
\]

olarak oluşturulur. Constraint için node seti bu facet'lerin node ID birleşiminden elde edilir:

\[
\mathcal{N}(G_f)=\bigcup_{f\in\mathcal{F}(G_f)} nodes(f)
\]

Bu yaklaşım corner node'larının birden fazla CAD face assignment'ına doğru biçimde katılmasını sağlar.

## 6. Linear HEX8 end-to-end verification

`VER-V130-001` unit cube üzerinde traction-equivalent nodal load ile axial uniform-stress problemidir.

Analitik referans:

\[
u=\frac{FL}{EA}
\]

ve toplam support reaction:

\[
\sum R_x=-F
\]

Uniform uniaxial state için von Mises:

\[
\sigma_{vm}=\left|\frac{F}{A}\right|
\]

olmalıdır.

Test, structured mesher çıktısını generic C ABI üzerinden gerçek Fortran model/DOF/sparse assembly/solver/stress-recovery yoluna verir.

## 7. Probe

Nearest-node probe, sorgu noktası `x_q` ile nodal coordinates arasındaki Euclidean mesafeyi minimize eder:

\[
n^*=\arg\min_n \|x_n-x_q\|_2
\]

Bu baseline spatial interpolation değildir.

## 8. Plane section selection

Plane:

\[
(\mathbf{x}-\mathbf{x}_0)\cdot\mathbf{n}=0
\]

olarak tanımlanır. Element node signed distances hem pozitif hem negatif tarafta bulunuyorsa veya tolerans içinde plane'e dokunuyorsa element cut setine alınır.

Bu V0.13'te yalnız intersected-element selection'dır; yeni cut-face triangulation veya Gauss-to-cut interpolation yapılmaz.

## 9. Export

CSV nodal coordinates ve varsa displacement field'ı taşır. Legacy VTK export, optional displacement scale ile deforme coordinates ve element scalar results taşır. Native project result schema'sının yerine geçen kalıcı binary format değildir.
