# V0.12 — Geometry / Section Theory Notes

## 1. Polygon area

Kapalı 2B contour noktaları `(x_i,y_i)` için signed area:

```text
A = 1/2 sum_i (x_i y_{i+1} - x_{i+1} y_i)
```

FEMCAE outer contour'u pozitif, hole contour'u negatif fiziksel katkı olarak toplar; giriş vertex orientation'ı tek başına hole anlamına gelmez.

## 2. Centroid

`c_i = x_i y_{i+1} - x_{i+1} y_i` olmak üzere:

```text
Cx = 1/(6A) sum_i (x_i + x_{i+1}) c_i
Cy = 1/(6A) sum_i (y_i + y_{i+1}) c_i
```

Birden çok contour'da signed first moments toplanır ve net alan üzerinden centroid bulunur.

## 3. Second moments about origin

```text
Ixx,0 = 1/12 sum (y_i^2 + y_i y_j + y_j^2) c_i
Iyy,0 = 1/12 sum (x_i^2 + x_i x_j + x_j^2) c_i
Ixy,0 = 1/24 sum (2x_i y_i + x_i y_j + x_j y_i + 2x_j y_j) c_i
```

Centroidal değerler paralel eksen teoremiyle:

```text
Ixx = Ixx,0 - A Cy^2
Iyy = Iyy,0 - A Cx^2
Ixy = Ixy,0 - A Cx Cy
```

## 4. Principal axes

```text
Iavg = (Ixx + Iyy)/2
R = sqrt(((Ixx-Iyy)/2)^2 + Ixy^2)
I1 = Iavg + R
I2 = Iavg - R
```

Principal angle baseline:

```text
theta_p = 1/2 atan2(-2 Ixy, Iyy-Ixx)
```

## 5. Polar area moment

```text
Jp = Ixx + Iyy
```

Bu yalnız polar second moment of area'dır. Non-circular beam torsion için Saint-Venant torsion constant genellikle `Jp`'den farklıdır.

## 6. DXF arc discretization

CIRCLE ve ARC entity'leri section integration öncesi kontrollü angular subdivision ile polygonal contour'a dönüştürülür. Bu nedenle curved-section property'lerinde discretization error vardır ve `circleSegments` / `arcMaxAngleDeg` ile kontrol edilir.

Analitik circle property üretim formülünün yerine polygon yaklaşımı kullanılması bilinçlidir; aynı pipeline arbitrary DXF contour'a uygulanır ve convergence test edilebilir.
