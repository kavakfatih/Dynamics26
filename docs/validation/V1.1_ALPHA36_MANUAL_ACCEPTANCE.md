# Dynamics26 V1.1.0-alpha.3.6 — Manual macOS Acceptance Protocol

Bu protokol otomatik CI'nın yerine geçmez. Amacı, Alpha.3.6 için yalnız gerçek macOS mouse/trackpad etkileşimiyle doğrulanabilecek `USER VALIDATED` durumunu tekrarlanabilir biçimde kaydetmektir.

## Ön koşullar

- Apple Silicon Mac üzerinde current `main` build'i çalışıyor olmalı.
- Geometry veya Mesh üzerinde seçim yapılabilecek gerçek bir proje açık olmalı.
- Test başlamadan önce document Undo geçmişindeki mevcut durum bilinmeli.
- Light ve Dark appearance ayrı ayrı kontrol edilmeli.

## A. Transient selection regresyonu

### A1 — Click / Replace

1. Geometry Face veya FEM Node seçim filtresini açın.
2. Bir entity'ye normal sol tıklayın.
3. Başka bir entity'ye normal sol tıklayın.

Beklenen:

- ikinci seçim birinci seçimin yerini alır,
- Navigator doğru parent project object üzerinde kalır,
- Details selection özeti doğru entity kind/count gösterir,
- document Undo history'ye raw selection girdisi eklenmez.

### A2 — Shift / Add

1. Bir entity seçiliyken `Shift + Click` ile ikinci entity ekleyin.

Beklenen:

- iki entity birlikte seçili kalır,
- yeni eklenen entity primary selection olur,
- Undo history değişmez.

### A3 — Command / Toggle

1. Seçili bir entity üzerinde fiziksel `Command + Click` kullanın.
2. Aynı kombinasyonla tekrar ekleyin.

Beklenen:

- ilk işlem entity'yi selection setinden çıkarır,
- ikinci işlem tekrar ekler,
- `Option/Alt` selection toggle olarak davranmaz.

### A4 — Empty / Esc

- boş alana normal Click → transient selection temizlenmeli,
- `Esc` → transient selection temizlenmeli.

## B. Window / area selection regresyonu

1. CAD ve FEM context'lerinde plain Left drag ile visible-only window selection yapın.
2. `Shift + drag` ile Add deneyin.
3. `Command + drag` ile Toggle deneyin.
4. `Alt + Left`, Middle ve wheel navigation'ın selection rectangle başlatmadığını doğrulayın.

Beklenen:

- rubber-band akıcı ve görünür,
- yalnız görünür entity'ler seçilir,
- window operation tek atomik selection değişimi gibi hissedilir,
- camera navigation selection ile çakışmaz.

## C. Named Selection create / normal view

1. Aynı domain ve aynı kind'dan bir veya birkaç entity seçin.
2. `Create Named Selection` kullanın.
3. Oluşan Named Selection'ı Navigator'dan seçin.

Beklenen:

- Named Selection Navigator'da kalıcı model object olarak görünür,
- Details: Name, Domain, Entity Type, Entities, Lifecycle ve Engineering Identity bilgilerini gösterir,
- viewport stored scope'un Geometry/Mesh context'ini açar,
- persistent highlight görünürdür,
- bu highlight transient `SelectionManager` seçimi gibi davranmaz.

## D. Edit Selection → Apply

1. Named Selection Details içinden `Edit Selection…` seçin.
2. Valid stored scope'un viewport'ta preload edildiğini kontrol edin.
3. Scope'u değiştirin.
4. `Apply Selection` kullanın.

Beklenen:

- edit sırasında Navigator/Details Named Selection üzerinde kalır,
- transient seçim hareketleri Undo history oluşturmaz,
- Apply tam **bir** Undo transaction üretir,
- yeni persistent scope normal view'a döner,
- Undo eski scope'u, Redo yeni scope'u geri getirir.

## E. Edit Selection → Cancel

1. Named Selection için tekrar `Edit Selection…` açın.
2. Viewport seçimini değiştirin.
3. `Cancel` kullanın.

Beklenen:

- edit session kapanır,
- persistent Named Selection scope değişmez,
- yeni document Undo entry oluşmaz.

## F. Stale scope güvenliği

### F1 — FEM

1. FEM Node/Element/Facet Named Selection oluşturun.
2. Mesh'i regenerate ederek generation'ı değiştirin.
3. Named Selection'ı seçin.

Beklenen:

- Named Selection `OutOfDate` görünür,
- doğru Mesh/entity-kind context korunur,
- eski numeric Mesh ID'leri selected/highlighted gibi gösterilmez,
- `Edit Selection…` repair yolu kullanılabilir,
- stale edit açıldığında eski ID preload edilmez; kullanıcı yeni kapsamı açıkça seçer.

### F2 — CAD

Geometry revision değişimine yol açan kontrollü bir işlem varsa aynı prensip kontrol edilir:

- stale scope silent runtime rebind/heal yapmamalı,
- eski topology identity seçiliymiş gibi gösterilmemeli.

## G. Fixed Support / Force consumer

1. Geçerli CAD Face Named Selection oluşturun.
2. Fixed Support veya Force Details'ta scoping method olarak `Named Selection` seçin.
3. İlgili Named Selection'ı atayın.
4. Preflight çalıştırın.

Beklenen:

- consumer Named Selection adını/resolved kapsamı gösterir,
- entity ID listesi kopyalanmış ikinci bir scope gibi davranmaz,
- valid scope preflight'tan geçer,
- stale/dangling scope açıkça OutOfDate/Error verir; legacy face'e sessiz fallback olmaz.

## H. Light / Dark görünürlük

Aşağıdaki durumları hem Light hem Dark appearance'ta gözle kontrol edin:

- hover / preselection,
- transient selected entity,
- persistent Named Selection highlight,
- Edit Selection preload,
- stale Named Selection diagnostic,
- Apply / Cancel kontrolleri,
- Navigator selected row,
- status badge / OutOfDate durumu.

Beklenen:

- seçili ve seçili olmayan entity kolay ayırt edilir,
- persistent highlight ile transient edit selection birbirine karışmaz,
- metin/ikon/çizgiler yeterli kontrasta sahiptir,
- custom parlak renk veya platform dışı görsel davranış yoktur.
